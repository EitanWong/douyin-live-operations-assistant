# 项目结构与架构

开发检索入口见 [Agent 导航](agent-guide.zh-CN.md)：离线索引覆盖源码符号、依赖/反向影响、资源调用与测试名称，由 `npm run agent:index` 生成，现有 `npm run check` 校验新鲜度；索引及其 Acorn 解析器不参与扩展运行。

demo/                     本地直播间模拟页面
scripts/                  构建、开发服务、语法检查与性能基准
tests/
  unit/                   规则、协议、服务和存储单元测试
  integration/            页面、扩展产物和开发更新集成测试

  guides/                 使用与实测指南

## 模块职责

| 模块 | 职责 |
| --- | --- |
| `src/app.js` | 装配引擎、面板、页面适配器、账本和持久化；管理启停、刷新与恢复 |
| `src/core/engine.js` | 互动条件、去重、礼物聚合、优先级调度、重试和运行快照 |
| `src/core/bot.js` | @指令、短菜单、房间游戏会话、回合与失败机制 |
| `src/core/phrases.js` | 默认话术和轮换 |
| `src/browser/protocol.js` | protobuf/gzip 解析、直播事件归一化、字符串 UID |
| `src/browser/adapter.js` | 观察页面连接、DOM 弹幕后备、请求优先发送及网页回退、控件诊断、Web Locks |
| `src/browser/request-sender.js` | 复用网页原生请求客户端、房间与账号校验、提交去重和本页公屏显示 |
| `src/browser/identity.js` | 当前房间主播、登录账号和管理员资料识别 |
| `src/data/gifts.js` | 连击增量、按日/月记账、多主播存储与报表 |
| `src/runtime/journal.js` | 合并快照写入、有限批次确认、失败保留和退避 |
| `src/runtime/delivery.js` | 持久发送意图、账号/文本/时间回显关联、未知结果与显式处理 |
| `src/runtime/inbox.js` | 有界事件缓冲、有限重试、故障隔离、资源断路与恢复导出 |
| `src/services/ai.js` | 兼容接口、请求校验、超时与响应处理 |
| `src/ui/panel.js` | Shadow DOM 面板、功能开关、表单与状态展示 |

规则引擎和数据模块不依赖面板。新增业务规则优先放入对应模块，通过应用层接线；Chrome API 留在扩展入口。

自动点赞和福袋红包通过 `src/tools/bundled.js` 统一注册。`runtime.js` 经 `cordis-adapter.js` 使用固定版本的 Cordis 核心，管理独立 Fiber、服务注入与卸载；项目作用域和操作网关继续负责同步撤权、资源回收与在途请求排空。菜单、页面和按钮路由从工具定义生成。工具不加入核心事件日志确认路径，也不接管账本和发送恢复。接口与新增工具方式见[包内工具插件开发](tool-plugins.zh-CN.md)。

## 消息流

1. `extension/page.js` 在 MAIN 世界观察直播页已有连接，把归一化事件交给隔离世界。在隔离脚本读取前，事件先进入有界缓冲。隔离脚本通过后台 `chrome.scripting.executeScript` 读取当前 `documentId` 的 MAIN 闭包队列，公开窗口消息不承载事件、控制命令或发送结果。MAIN 仍与网页共享环境，网页本身及其客户端不构成可信平台回执。
2. `extension/content.js` 串行交接事件。运行期间和独立礼物记账均先经后台写入事件日志，再交给应用层。追加使用稳定 ID，重试不会生成重复日志；回放每页最多 256 条。
3. 应用层更新观众资料与账本任务，引擎执行互动规则、礼物连击合并和游戏逻辑。
4. 调度器优先处理礼物，并为等待中的机器人回复提供调度机会。每条弹幕先检查网页原生请求客户端，准备不可用时分别等待300、600毫秒再次检查；管理员请求不可用时先尝试普通弹幕请求。本页公屏显示队列缺失不阻止请求，已完成回执也不占满请求准备容量。反复确认仍不可用才回退网页编辑器；模式准备后写入前、控件就绪后及发送意图保存后仍复查请求，按钮等待期间也间隔300毫秒复查，恢复即清理本条脚本草稿并改用请求。网页控件就绪即继续，不固定等待120毫秒；异步粘贴未落入编辑器前不切换通道，避免迟到粘贴留下草稿。下一条消息重新从请求开始，人工草稿始终优先，真实@保持请求发送。两条通道都不可用时保留队列并退避；请求一旦提交，同次发送不因拒绝或未知结果改走网页重发；平台明确拒绝后的队列重试仍从请求检查开始。
5. 自动发送前保存包含在途任务的检查点；已处理事件在快照保存成功后分批确认。

聊天准备票据在提交前因草稿、暂停、保存失败或扩展准备响应超时而取消时，由持有者释放。未提交票据超过10秒不再有效，也不再占用容量；已经开始提交的票据不允许释放，在途回执不因准备超时或容量被淘汰，完成回执保留去重并按五分钟期限或容量需要回收。票据容量上限仍为128，旧票据失效后不能重新发送。

`extension/background.js` 负责扩展存储、房间范围校验、账本事务和已授权的 AI 请求。后台会被 Chrome 回收，业务状态保存在持久存储中。

## 状态与恢复

- 配置、运行快照、事件日志和收入账本按房间分开；AI 密钥按服务域名保存。
- 快照记录待发送任务、礼物累计、游戏会话、去重和冷却状态，以及待入账礼物。快照对象与运行状态隔离。
- 快照写入只保留一个在途写入和一个最新待写入状态；检查点必须等待实际保存成功。
- 事件日志每批最多确认 50 条，确认失败保留重试。该批次只影响存储交接，不限制弹幕发送频率。
- 页面刷新保存续跑意图，缓存返回恢复观察器。同房间通过 Web Locks 协调运行权。只有用户手动暂停会停止场控；配置保存在线更新，不清空互动现场。

发送前先保存待发送状态，真实点击前再保存点击意图。保存意图后若仍未调用请求或点击网页控件，适配器明确报告未提交，原任务保留重试；实际提交后的异常优先按未知结果处理。本人结构化弹幕回显在本人事件过滤之前匹配；超时、刷新与点击后中断进入未知状态，禁止自动重发。用户显式重试仍可能重复，不承诺恰好一次。尚未写入日志的事件、平台断线期间未重放的数据和被清除的浏览器存储无法靠本地快照补回。详细测试见[验证记录](../reviews/validation.zh-CN.md)。

## 构建

`scripts/build.mjs` 使用 esbuild 从真实 ESM 入口生成单文件用户脚本、MAIN、隔离脚本和后台 bundle，保留导入别名、模块作用域和副作用；静态资源单独复制。源码目录分类不改变产物入口：Chrome 仍加载 `dist/chrome-extension`。

Cordis 适配层随应用依赖由 esbuild 内置进油猴和扩展隔离脚本；本地模拟器从 `dist/tool-runtime.js` 加载同一适配层。无需框架运行时网络依赖，也不改变 MAIN 与后台入口。

本地模拟器从源码模块启动；`npm run demo` 将根地址映射到 `demo/index.html`。开发更新由 `scripts/dev.mjs` 监听 `src/`、`extension/` 和 `scripts/`，构建成功后才发布新标识。

## 资源故障与降级

内容脚本交接和 MAIN 桥接各有 4,096 条 / 8 MiB 缓冲，解码最多排队 256 帧 / 16 MiB。瞬时故障最多重试三次，之后隔离；配额、80% 存储水位和业务背压立即打开断路。原始持久日志保留，恢复入口重新处理；不能写入或缓冲耗尽后的新增数据计为缺口。内存缓冲不是持久化保证。

礼物日志、待入账事实和感谢任务分别保留。待入账事实保存原采集时间，持久化快照中的事实可跨长时间故障继续入账；新到的历史补推仍按原时间规则过滤。未确认发送最多 100 条，普通待发送与礼物结算有独立容量边界。配额不足时不自动删除未完成业务数据，提供恢复导出并明确显示降级状态。

- `browser/room-context.js` 统一路径与 `room_id` 的房间键及切房检查；房间地址键与开播 `roomId` 分开。无关查询参数变化不停止采集。
- `runtime/tool-host.js` 集中工具的页面策略、存储与发送适配。下播先经过现有场次状态校验，再停止工具；不等待账本写入，也不接受其他场次或乱序的旧下播。

- 福袋活动在房间锁内重读、预留共享记录，扩展保存在后台 IndexedDB，用户脚本使用 GM 存储；按房间及账号隔离。旧 sessionStorage 副本确认迁移后才删除。明确未派发可撤销预留，未知结果不重试。
- `extension/protocol-cache.js` 每次 worker 启动重建一次轻量索引，此后只读取当页原帧。协议写入队列独立于礼物账本，保留水位、过期清理与幂等语义。

包内静态工具注册是当前受维护代码的发布模型；Cordis 与能力网关不提供敌对插件沙箱。同线程同步死循环、页面篡改原生客户端或网络数据不能靠这些修复隔离。


## AI 组合与实时观察（2026-11-02）

### 按任务选择模型与人物投影（2026-11-07）

`services/ai-task-config.js` 统一为两种文字模型：reply 沿用前台回复组合，快速判断需求与互动；research 和 profile 任务统一选择后台研究模型，执行深度推理、搜索、知识整理与人物关系任务。后台未开启或连接未填写完整时回退reply，没有独立人物覆盖。默认后台模板为gpt-6.1-terra、Responses接口和high推理深度；兼容Chat Completions网关，支持JSON/.env导入，订阅服务须提供兼容授权网关。Omni预设不重写已选后台连接；视觉、语音和实时感知仍由 `ai-pipeline.js` 管理。后台密钥共用research域名槽位，不进入配置导出、任务或广播；旧profile共享组不再参与投影。

`continuous-research.js` 将稳定账号弹幕、未归属弹幕、audio/video/omni最终识别纳入同一发现队列。每批最多六条尚未处理资料形成纯数据快照，保留ID、采样起止、来源和未知身份，动态读取函数不进入持久任务。长任务期间的积压继续处理，不受五分钟或最近3/6条发现窗口截断；普通资料去重水位不按100条或一天清除，已确认公开主页保留每日复查冷却。部分识别、静音和未来采样不提交；删除或清空使旧任务作废。现场保存和任务结束唤醒loop，30秒alarm兜底；无新资料时等待。默认持续研究/画像开启、研究预算均0，只有用户正数才限制。网页原文进入唯一知识库，模型结论保持可重建投影，前台复用证据快速回复。

开启 `ai.assistant.research.profileEnabled` 后，稳定账号研究完成时，`profile-insights.js` 从最近最多16条、12000字的本人账号原话生成可重建人物投影。事实、明确关系、一般知识和心理假设分开，每项保留逐字原话引用；心理假设必须说明局限。使用同一后台研究模型，额外调用计入用户可选的同房小时研究额度，默认0不限，不发送原始账号标识。失败在任务结果报告，已完成研究与原文保留。

投影由后台唯一写入 `profile-insights`，按房间/主播隔离。查询复核遗忘版本、原文ID、时间和逐字内容，最多复用30天；图谱从有效投影和原始档案重建，保留待核实状态，不按重名合并。推理不持有写队列，删除无需等待模型；提交前重读原文，迟到结果不能恢复已遗忘人物。来源仍是事实边界，投影不能代替原始记录。

- `services/ai-pipeline.js` 集中组合、百炼地域与业务空间、感知/回复配置投影；预设不覆盖原有文字连接。
- `browser/omni-realtime.js` 用官方 WebRTC 持续传输共享音频与 1 FPS 缩小画面；扩展后台独立交换 SDP，配置确认后才发送媒体。仅稳定完成的识别结果进入有界证据窗口；停止与旧代数隔离。
- `services/media.js` 继续支持独立视觉、官方 Qwen ASR 格式和自定义 Omni 分段识别。`LiveMediaAnalyzer` 统一两类采集的生命周期。
- `services/ai-context.js` 组织 RAG 与共享现场资料，按完整记录裁减并披露遗漏；`ai.js` 保护 JSON 整包上限，所有任务可由现有文字模型或 Omni 文本模型执行。
- 模型识别为直播数据查询后携带结构化汇总事实版本；入队、排队及实际发送前复核，数值或状态变化后不再发送旧答案。

协议依据、预算与验收边界见 [实施记录](../research/ai-realtime-implementation-2026-11-02.zh-CN.md)。WebRTC 结果由 VAD 触发，不代表固定窗口全覆盖；真实百炼与长时直播尚未验收。

## 产品界面基础（2026-11-02）

`ui/product` 使用 React 19、Mantine 9 和 TanStack Table 9。`bridge.js` 是渐进迁移边界：原 Panel/AISettings/AnchorDashboard 仍拥有唯一草稿、校验、领域数据和操作；桥只投影当前页的不可变视图快照，React 独占嵌套 Shadow Root 的 DOM。编辑派发一次原事件，操作调用一次原控件，筛选和导出继续走原领域数据。源控件在成功挂载后不可见且 inert，保留可测尺寸供旧图表控制器使用；加载/渲染失败恢复兼容界面。销毁释放订阅、React root 与图表。

2026-11-05：投影通过 `snapshot.js` 结构共享未变化分支，去掉完整 JSON 签名副本；格式函数按身份比较，状态变化不重新提交相同图表配置。后台页面内部变更不触发前台投影，控件强引用只属于当前投影，销毁释放快照。事件 Inbox 在连续处理200条或超过8ms时合作让出主线程，仍保持单消费者；最终关闭清空缓冲并忽略迟到完成，缓存暂停不走最终关闭。

这是一层兼容迁移，并未删除字符串模板、WorkspaceLayout 或旧控制器，也未将全部配置交给 React/useForm。后续应按页面把视图模型从领域控制器直接输出，再删除对应 DOM 投影和旧布局代码；不再添加第三份状态。TanStack 当前承担表格列/行模型，源分页和排序仍按领域语义执行，没有启用全库排序或虚拟化。ECharts 接收原图表选项，在可见区拥有独立可交互实例；会增加少量图表实例开销。

外观由 `appearance.js` 定义模式、配色和材质白名单；`theme.js` 统一读写、跨窗口同步和失败回滚。配色基于 Radix Colors 的 12 阶亮暗色板，原 Solid Glass 仍为默认。`theme-palette.js` 统一生成宿主和组件主题变量，不修改直播网页 document 的主题；Select 弹层限定在本 Shadow Root。布局使用浮动窗口的容器查询，不使用默认视口定位 AppShell。Liquid Glass 是 CSS 模糊、高光和半透明表面的可选材质，不声称复刻苹果系统渲染；支持减少透明度、强制颜色与不支持 backdrop-filter 的退化。

AI pipeline 的 Zod schema 在配置边界解析一次并保留扩展字段，中文错误和字段路径供原表单与新界面共用。本轮没有替换音视频传输、RAG 检索、权限网关、发送队列或存储，没有凭普通模型 SDK 推定支持 Omni 实时。

### 成熟底层适配（2026-11-02）

本地检索由 MiniSearch 管理倒排索引与 BM25+；`retrieval.js` 只保留中文切词、原文分块与证据预算。索引是本次查询的派生数据，不与其他房间共享可变状态，配置仍是唯一持久资料来源。`completion-stream.js` 用 eventsource-parser 解析协议事件，并用 Zod 校验文本；`intent.js` 用判别联合限定意图负载。

Chrome 后台的 DurableStorage 使用 Dexie 事务，保持原生数据库版本 1 与 journalOrder 索引，记录与用量计数同时提交。仅后台拥有写入职责；原迁移“先校验已提交副本，再删除旧副本”规则不变。感知每个实例有独立 XState actor，active 范围持有采集资源和取消令牌；停止/结束/启动失败均退出 active，在途采样请求收到 AbortSignal。

可见字段网格与设置页卡片分别使用 Mantine SimpleGrid / Stack。新界面接管时暂停旧 WorkspaceGrid 的观察和测量，失败回退时恢复。原控制器与 UI 桥仍在，不能据此认为旧模板与兼容开销已全部消失。选型、版本、许可和验证见[接入记录](../research/mature-foundation-integration-2026-11-02.zh-CN.md)。

### 受限 Agent、观众记忆与缓存（2026-11-02）

`ai/harness.js` 用 XState actor 管理独立任务生命周期；`ai/research-graph.js` 使用 LangGraph.js 浏览器运行时执行规划→工具→观察循环，`ai/checkpoint-store.js` 将原生检查点与pending writes保存到Dexie。`extension/ai-background.js` 是唯一Chrome后台宿主；`ai/continuous-research.js` 按新近持久对话、去重与预算发现任务，原文知识经MiniSearch回到前台。研究不持有公屏发送器；新任务中断最多恢复2次，已完成且落盘的工具不重复，在途请求可能重试计费。旧版任务保留中断状态。油猴和演示版只支持依赖页面存活的手动任务。完整边界见[浏览器 Agent Harness](browser-agent-harness.zh-CN.md)。

`ai/audience-memory.js` 管理主播范围内、30天/100位观众的有界事实；同名不合并，礼物累计去重，删除水位阻止旧事件恢复。目标记忆以不含UID/secUID的形式注入回复，用户可查看、纠正和删除。`ai/skills.js` 仅解析声明式提示包，不执行代码。公开网页提取使用linkedom worker + Readability，只读取明确链接的已授权文字，不分析主页视频或进行跨平台身份匹配。

`services/retrieval.js` 的lru-cache缓存MiniSearch派生索引，完整资料元数据变化会失效；实时答案不缓存。媒体上下文区分最新语音、顺序视觉采样和音画联合观察，显示覆盖与年龄。冷场任务要求新鲜现场线索，出现新弹幕或关闭开关后丢弃迟到结果。详见[实施记录](../research/agent-harness-memory-2026-11-02.zh-CN.md)。

## 2026-11-02 布局契约补充

可见工作台的结构决策集中在 `src/ui/product/layout.js`：cards / fields / metrics 使用 Mantine 容器 SimpleGrid，stack / row 使用 Stack / Group；卡片表面和跨行语义独立。兼容桥先过滤不可见节点、展开纯布局包装，再生成快照。可见层不再以源类名重复声明网格或 display:contents。只有一个布局控制者，新界面就绪时暂停 WorkspaceGrid 与 AdaptiveLayout，失败回退时恢复。

分类统一使用 Mantine Tabs；折叠状态由桥接源唯一持有，跳转到隐藏分区会先展开其祖先。工具栏显示操作，保存状态与运行状态进入底部状态区。详细决策、术语和边界见 [统一布局研究](../research/layout-foundation-2026-11-02.zh-CN.md)。
