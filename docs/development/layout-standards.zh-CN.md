# 工作台组件尺寸与排列标准

尺寸的唯一来源是 `src/ui/product/layout.js` 的 `PRODUCT_DIMENSIONS` 与 `PRODUCT_COMPACT_DIMENSIONS`。所有功能页共用 Mantine 展示层，不在单个页面另加尺寸补丁。

## 一页展示的优先级

1. 先按标准尺寸、等宽卡片自适应排版，尽量在一页中完整展示。
2. 标准排版超出可用高度时，收紧内边距、分组间距、标题行、卡片高度和控件尺寸；卡片最小宽度在密度探测中保持稳定。
3. 紧凑排版仍然超出时，保留紧凑尺寸，再通过页面滚动访问全部内容。

`src/ui/product/fit.js` 的 `WorkspaceFit` 是密度选择的唯一写入者。它按上述顺序测量当前页面的实际高度、内容区内边距与可用高度；标准能放下就不再压缩，只有两种规整排版都放不下才启用页面滚动。密度是窗口与内容推导出的展示状态，不新增用户配置。窗口缩放、页签切换、内容刷新、详情展开和字段自动增高后会重新判断，空间增大后可回到标准模式。隐藏窗口不重置选择，允许 1px 的亚像素舍入误差。

| 组件 / 间距 | 标准 | 紧凑 |
| --- | --- | --- |
| 单行输入框、选择器、按钮基准高度 | 36px | 32px |
| 卡片标题行基准高度 | 36px | 24px；含操作的标题行保留控件点击高度 |
| 多行文本输入最小高度 | 96px | 72px |
| 功能卡片换行基准宽度 | 280px | 280px |
| 普通卡片统一外框高度上限 | 380px | 320px |
| 短窗口卡片高度下限 | 240px | 240px |
| 普通表单列最小宽度 | 200px | 200px |
| 图表范围等行内选择器基准宽度 | 160px | 160px |
| 数据指标列最小宽度 | 140px | 140px |
| 指标单元最小高度 | 64px | 52px |
| 卡片内边距 | 16px | 8px |
| 卡片内分组间距 | 12px | 6px |
| 卡片、页面区块之间 | 16px | 8px |
| 内容区内边距 | 20px | 12px |
| 图表绘图区高度 | 220px | 180px |

字体不整体缩放。长标题与按钮仍允许换行，输入说明、错误、草稿和操作不因紧凑模式而删除或折叠。

## 卡片排列与滚动

全局采用现有 Mantine Flex 与浏览器原生 `flex-wrap` / `flex-grow`：普通卡片外框等高、每行平分宽度，尾行按实际卡片数铺满，无空列和参差列尾。换行基准共用 `PRODUCT_DIMENSIONS.cardMinWidth`（280px），空间不足自动减列，窄窗口恢复单列。业务分组和显式通栏保留分界，不把内容按高度重新排序。

普通卡片外框高度取 `clamp(240px, 100cqh, cardHeight)`，其中 `cqh` 来自浮窗内容区。高度上限随密度由380px降到320px；短窗口降到可用内容高度，最低240px，剩余通过页面滚动访问。卡片标题固定在正文之外，正文用 `min-height:0` 和 `overflow:auto` 承接任意展开内容、长文本、实时记录及自动增高字段。展开不会再把自身外框或相邻卡片无限撑高。字体、控件和图表不缩放；完整内容支持滚动或独立放大。

独立高级设置、操作记录和使用说明属于通栏折叠区：关闭后只有紧凑标题，打开时正文自然增高到同一高度上限后滚动。嵌在卡片里的折叠区交给卡片正文滚动，不再套第二层限高。通栏和独立卡片同样限制长正文；不再对图表单独设一套高度。普通表单使用 Mantine SimpleGrid 容器查询，指标使用 Group，均按实际内容换行。

已移除自制 CardFlow、逐卡片 ResizeObserver 和网格行跨度写入。浏览器原生布局即时响应窗口拖动和宽度变化；WorkspaceFit 仅观察内容区与页面外框，使用 rAF 合并密度选择。展开/收起使用现有 Motion 可打断弹簧动画，减少动态效果时立即切换；拖动缩放不叠加位置补间，避免追赶鼠标或反复测量每个内部动画帧。隐藏窗口不测量，销毁时断开观察器并取消待处理帧。

视觉顺序与 DOM / 键盘顺序一致，不搬移、克隆或重新挂载字段。编辑草稿、焦点与正文/页面滚动位置保留，滚动区有键盘焦点与可访问名称，滚到边界后允许滚动链传递到页面。宽表格保留横向滚动。独立放大视图解除正文高度上限，由弹窗统一滚动。

任意自然内容高度、完全等高外框、零内部留白无法同时保证。本方案以规整外框和完整内容可访问为约束：短正文允许卡片内部余量，长正文滚动；明确不再承诺自然高度瀑布流能形成平齐底边。不同页面不另外引入打包库或高度算法。

成熟方案依据：[Mantine Flex](https://mantine.dev/core/flex/) 的换行、对齐和 gap；[Mantine SimpleGrid](https://mantine.dev/core/simple-grid/) 的容器查询、auto-fit 与 autoRows。现有依赖已具备所需能力，无新增包。

## 独立放大视图

设置卡片、图表、指标、表格、记录集合、折叠详情，以及 AI 最终答案和处理链路均提供角标按钮。按钮有可访问名称与弹窗语义；弹窗由 Mantine Modal 管理焦点、遮罩与关闭，使用 pop 动画，尊重系统“减少动态效果”。Escape 关闭弹窗且不收起工具窗口，关闭后焦点回到触发按钮。弹窗适配工具窗口尺寸，内容过长时可滚动，图表获得更大绘图区。

独立视图从同一桥接快照读取实时数据，编辑和操作调用同一原控制器，不新增业务状态存储。背景暂时不可交互，弹窗内不继续嵌套放大入口；页签变化或目标被移除时关闭，知识编辑等业务弹窗保持优先级。表格/记录的独立搜索与分页只影响该视图，不截断原数据和导出。

同一组件只保留一个放大入口：卡片或折叠区已有入口时，其内部图表、表格、指标和记录不重复添加按钮，也不预留空的按钮行。独立呈现的数据组件仍有自己的入口；AI 最终答案与处理链路是明确的独立内容，保留各自入口。

## AI 分类与问答结果

AI 设置分为连接与模型、直播感知、知识与搜索、观众与研究、问答测试、本地与性能、高级设置。模型连接不再混入设备准备和观众资料；本地设置进一步分为回复/识别选择、设备准备、额度/时限三组。所有原配置字段仅保留一份，跨分类切换保留草稿与密钥，错误仍可定位所属分类。

问答测试以“本次最终答案”为首要输出，问题、用量、实际处理链路、来源和检查分区展示。历史回答折叠归档，批量场景默认折叠。链路直接来自测试服务已发生的上下文准备、模型调用、意图识别、搜索或缓存、结果检查、完成/失败/取消事件，显示开始后的实际耗时，不伪造模型内部思考或未执行步骤。进行中可查看已发生的步骤；最终答案保持纯文本与导出边界。观众答案正文不含来源角标，不播报本地/联网回答、接口或搜索失败；查到直接回答，没查到自然说明具体未知。来源依据使用独立 citationIndices 元数据核对，结构化 sources 和旧式中英文编号均兼容；搜索、有效缓存、后台研究与评测共用这一边界。原始故障、资料来源及实际使用标记仅在测试/诊断区展示，不拼回公屏正文。

短窗口压缩工具栏，二级页签以单行横向滚动显示；导航、分区选择器和消息可滚动访问。紧凑/滚动模式的状态区最高为控件高度加 12px。尺寸判断以浮窗内容区为准，不依赖网页视口宽高。

不按内容高度重新排序业务数据，不将字段分配到多个状态容器；所有功能页共用等高、有界正文和通栏折叠规则。

修改后至少检查：全部功能页及二级页在桌面/窄屏的默认与全部展开状态；标准、紧凑、短窗口滚动；窗口变大恢复标准；同组卡片等高、同行等宽、末行铺满、无交叠、统一间距和无横向溢出；长文本、动态内容、反复收起/展开；鼠标拖动位置与大小、键盘连续缩放；草稿/焦点/滚动保留；放大视图同步、Escape、减少动效与生命周期清理。测量和截图保存到当次任务证据目录。有限尺寸验收不能证明所有可能内容与设备组合，后续新增组件仍需遵守该边界并回归。

## 侧栏与 Liquid Glass 基础材质

桌面侧栏展开宽 184px、折叠宽 64px，按钮为 40px 点击区域。图标与标签使用明确的内部网格；折叠时图标居中、完整名称留在可访问标签与悬停提示中，折叠按钮遵循同一规则。660px 及以下改为可滚动功能菜单，恢复完整标签。左右位置与折叠状态只由原导航控制器保存，展示层订阅其变化。

默认材质使用 Liquid Glass；已保存的原始玻璃 / 实色选择继续生效。实现唯一来源为 src/ui/liquid-glass.js：外窗背景使用本地 SVG 位移图折射与磨砂，高光、卡片、输入框共享材质变量；文字和图表不进入滤镜。只保留一个背景模糊层，无远程资源或逐卡片鼠标监听。上游参考与许可见 vendor/liquid-glass-react。减少透明度、强制颜色及不支持背景滤镜的环境使用降级样式。
