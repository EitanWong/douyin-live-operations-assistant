# 工作台组件尺寸与排列标准

尺寸的唯一来源是 `src/ui/product/layout.js` 的 `PRODUCT_DIMENSIONS` 与 `PRODUCT_COMPACT_DIMENSIONS`。所有功能页共用 Mantine 展示层，不在单个页面另加尺寸补丁。

## 一页展示的优先级

1. 先按标准尺寸、自然内容高度排版，尽量在一页中完整展示。
2. 标准排版超出可用高度时，收紧内边距、分组间距、标题行和控件尺寸，并利用更小的卡片最小宽度增加列数。
3. 紧凑排版仍然超出时，保留紧凑尺寸，再通过页面滚动与过长卡片的正文滚动访问全部内容。

`src/ui/product/fit.js` 的 `WorkspaceFit` 是密度选择的唯一写入者。它按上述顺序测量当前页面的实际高度、内容区内边距与可用高度；标准能放下就不再压缩，只有两种自然排版都放不下才启用高度上限。密度是窗口与内容推导出的展示状态，不新增用户配置。窗口缩放、页签切换、内容刷新、详情展开和字段自动增高后会重新判断，空间增大后可回到标准模式。隐藏窗口不重置选择，允许 1px 的亚像素舍入误差。

| 组件 / 间距 | 标准 | 紧凑 |
| --- | --- | --- |
| 单行输入框、选择器、按钮基准高度 | 36px | 32px |
| 卡片标题行基准高度 | 36px | 24px；含操作的标题行保留控件点击高度 |
| 多行文本输入最小高度 | 96px | 72px |
| 功能卡片最小宽度 | 320px | 280px |
| 普通表单列最小宽度 | 200px | 200px |
| 图表范围等行内选择器基准宽度 | 160px | 160px |
| 数据指标列最小宽度 | 140px | 140px |
| 指标单元最小高度 | 64px | 52px |
| 卡片内边距 | 16px | 8px |
| 卡片内分组间距 | 12px | 6px |

字体不整体缩放。长标题与按钮仍允许换行，输入说明、错误、草稿和操作不因紧凑模式而删除或折叠。

## 卡片排列与滚动

卡片使用 Mantine Flex 按原始顺序自动换行，充分利用所在内容区的宽度，可以排列成一列、两列、三列或更多列。同行等宽、等高，上下边缘对齐；末行剩余空间由卡片均分，说明、显式通栏配置和折叠操作占满整行。字段与指标继续使用 Mantine SimpleGrid，列数按实际项目封顶。

标准与紧凑模式中，卡片没有固定高度、最小高度或强制内部滚动。每行由内容自然决定高度，避免短内容也占据 280–400px。只有最终滚动模式中，过长卡片才限制为最高 560px，且不会高于实际内容可视区；标题留在正文之外，正文滚动显示全部字段。页面同时保留纵向滚动，完整页面无需依靠逐个卡片滚动拼接才能浏览。

卡片正文是该卡片的唯一纵向滚动区；编辑和记录列表不另设纵向高度上限，宽表格保留横向滚动。内部使用原生 `overscroll-behavior:auto`，到达边界后的下一次滚轮手势接续页面；最外层内容区保留 `contain`，避免滚动直播间背景。正文可用 Tab 聚焦并以方向键、PageUp/PageDown 滚动，分区跳转与错误字段聚焦仍能到达原控件。重新测量密度时保留页面及卡片的滚动位置，原 DOM、草稿和事件所有者不变。

短窗口压缩工具栏，二级页签以单行横向滚动显示；导航、分区选择器和消息可滚动访问。紧凑/滚动模式的状态区最高为控件高度加 12px。尺寸判断以浮窗内容区为准，不依赖网页视口宽高。

不使用按高度排序、多栏瀑布流、绝对定位填空、密集回填或测量后搬动表单节点。视觉顺序与 DOM、键盘顺序一致。

修改后至少检查：标准一页展示、紧凑一页展示、紧凑后滚动三种结果；窗口变大恢复标准；同行边缘、末行填满、统一间距、横向溢出；长文本、展开详情、空状态和有数据图表；草稿、焦点与滚动位置在重新测量后仍保留。测量和截图保存到当次任务证据目录。

## 侧栏与 Liquid Glass 基础材质

桌面侧栏展开宽 184px、折叠宽 64px，按钮为 40px 点击区域。图标与标签使用明确的内部网格；折叠时图标居中、完整名称留在可访问标签与悬停提示中，折叠按钮遵循同一规则。660px 及以下改为可滚动功能菜单，恢复完整标签。左右位置与折叠状态只由原导航控制器保存，展示层订阅其变化。

默认材质使用 Liquid Glass；已保存的原始玻璃 / 实色选择继续生效。实现唯一来源为 src/ui/liquid-glass.js：外窗背景使用本地 SVG 位移图折射与磨砂，高光、卡片、输入框共享材质变量；文字和图表不进入滤镜。只保留一个背景模糊层，无远程资源或逐卡片鼠标监听。上游参考与许可见 vendor/liquid-glass-react。减少透明度、强制颜色及不支持背景滤镜的环境使用降级样式。
