# 工作台组件尺寸与排列标准

以下内容区尺寸的唯一实现来源是 `src/ui/product/layout.js` 的 `PRODUCT_DIMENSIONS`；样式变量和网格断点由它生成。所有功能页经同一展示层应用，不在各页面追加独立尺寸补丁。

| 组件 / 间距 | 标准 |
| --- | --- |
| 内容区与工具栏按钮、单行输入框、选择器、卡片标题行 | 32px 基准高度 |
| 多行文本输入 | 最小 96px，继续按内容展开 |
| 普通表单列 | 最小 200px，空间不足时单列 |
| 图表范围等行内选择器 | 160px 基准宽度，可随窄窗口收缩 |
| 数据指标列 | 最小 140px；指标单元最小高 64px，内边距 8px |
| 功能卡片 | 单列或双列，每列最小 320px；窄窗口占满可用宽度 |
| 卡片内边距 | 16px |
| 字段、指标、卡片内分组间距 | 12px |
| 卡片之间、页面区块之间 | 16px |
| 图表绘图区 | 220px 高 |

卡片使用按原始顺序排列的普通网格。同一行等宽、等高，上下边缘对齐；说明、通栏区块及每组最后一张未配对卡片占满整行。宽度按所在容器计算，避免侧边栏或浮窗缩放后仍沿用浏览器宽度。

卡片高度由同行内容决定。长说明、校验错误、展开详情和多行按钮标题可以自然增高，不设置会裁切内容的固定高度。字段说明放在输入框之后。折叠标题采用同一 32px 基准，普通通栏折叠区上下各留 8px；作为并列卡片的折叠区沿用 16px 卡片内边距。

不使用多栏瀑布流、按高度排序、绝对定位填空、密集回填或测量后搬动表单节点。视觉顺序与 DOM、键盘顺序一致，草稿、原始事件和详情展开状态继续由原控制器持有。

修改布局后至少检查：宽窄窗口下同一行边缘、卡片宽度、16px 行间距、孤立单元格、横向溢出，以及长文本、详情展开、空状态和有数据图表。尺寸测量和截图与行为回归一起保存到当次任务证据目录。

## 侧栏与 Liquid Glass 基础材质

桌面侧栏展开宽 184px、折叠宽 64px，按钮为 40px 点击区域。图标与标签使用明确的内部网格；折叠时图标居中、完整名称留在可访问标签与悬停提示中，折叠按钮遵循同一规则。660px 及以下改为可滚动功能菜单，恢复完整标签。左右位置与折叠状态只由原导航控制器保存，展示层订阅其变化。

默认材质使用 Liquid Glass；已保存的原始玻璃 / 实色选择继续生效。实现唯一来源为 src/ui/liquid-glass.js：外窗背景使用本地 SVG 位移图折射与磨砂，高光、卡片、输入框共享材质变量；文字和图表不进入滤镜。只保留一个背景模糊层，无远程资源或逐卡片鼠标监听。上游参考与许可见 vendor/liquid-glass-react。减少透明度、强制颜色及不支持背景滤镜的环境使用降级样式。
