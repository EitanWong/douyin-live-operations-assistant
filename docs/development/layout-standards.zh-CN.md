# 工作台组件尺寸与排列标准

尺寸的唯一来源是 `src/ui/product/layout.js` 的 `PRODUCT_DIMENSIONS` 与 `PRODUCT_COMPACT_DIMENSIONS`。所有功能页共用 Mantine 展示层，不在单个页面另加尺寸补丁。

## 一页展示的优先级

1. 先按标准尺寸、自然内容高度排版，尽量在一页中完整展示。
2. 标准排版超出可用高度时，收紧内边距、分组间距、标题行和控件尺寸，并利用更小的卡片最小宽度增加列数。
3. 紧凑排版仍然超出时，保留紧凑尺寸，再通过页面滚动访问全部内容。

`src/ui/product/fit.js` 的 `WorkspaceFit` 是密度选择的唯一写入者。它按上述顺序测量当前页面的实际高度、内容区内边距与可用高度；标准能放下就不再压缩，只有两种自然排版都放不下才启用页面滚动。密度是窗口与内容推导出的展示状态，不新增用户配置。窗口缩放、页签切换、内容刷新、详情展开和字段自动增高后会重新判断，空间增大后可回到标准模式。隐藏窗口不重置选择，允许 1px 的亚像素舍入误差。

| 组件 / 间距 | 标准 | 紧凑 |
| --- | --- | --- |
| 单行输入框、选择器、按钮基准高度 | 36px | 32px |
| 卡片标题行基准高度 | 36px | 24px；含操作的标题行保留控件点击高度 |
| 多行文本输入最小高度 | 96px | 72px |
| 功能卡片最小宽度 | 320px | 280px |
| 普通表单列最小宽度 | 200px | 200px |
| 图表范围等行内选择器基准宽度 | 160px | 160px |
| 数据指标列最小宽度 | 140px | 140px |
| 指标单元最小高度 | 64px | 52px |
| 卡片内边距 | 16px | 8px |
| 卡片内分组间距 | 12px | 6px |
| 卡片、页面区块之间 | 16px | 8px |
| 内容区内边距 | 20px | 12px |
| 图表绘图区高度 | 220px | 180px |

字体不整体缩放。长标题与按钮仍允许换行，输入说明、错误、草稿和操作不因紧凑模式而删除或折叠。

## 卡片排列与滚动

卡片使用成熟的 Masonry 4.2.2，在统一列宽下按内容自然高度紧密排列。每个后续卡片接到当前最短的可用列；显式通栏配置和折叠操作仍占完整行，字段与指标继续使用 Mantine SimpleGrid。移除同行拉齐与固定外框高度，短卡片内部不会为了匹配旁边长卡片而产生留白。DOM 与键盘顺序保留输入顺序，视觉阅读按卡片顶部从上到下、同高度从左到右。宽度与间距以所在内容区计算；列末的自然边界和统一可读性间距不通过拉高短卡片填平。

标准、紧凑与滚动模式均保持卡片自然高度，不强制内部纵向滚动。页面是主要纵向滚动区；宽表格仍可横向滚动。编辑/记录列表不另设纵向高度上限，分页和搜索保留。最外层内容区使用 `overscroll-behavior:contain`，避免滚动直播间背景。密度重新测量时保留页面位置、原始草稿和事件；Masonry 仅定位原卡片，不克隆或排序表单。

## 独立放大视图

设置卡片、图表、指标、表格、记录集合、折叠详情，以及 AI 最终答案和处理链路均提供角标按钮。按钮有可访问名称与弹窗语义；弹窗由 Mantine Modal 管理焦点、遮罩与关闭，使用 pop 动画，尊重系统“减少动态效果”。Escape 关闭弹窗且不收起工具窗口，关闭后焦点回到触发按钮。弹窗适配工具窗口尺寸，内容过长时可滚动，图表获得更大绘图区。

独立视图从同一桥接快照读取实时数据，编辑和操作调用同一原控制器，不新增业务状态存储。背景暂时不可交互，弹窗内不继续嵌套放大入口；页签变化或目标被移除时关闭，知识编辑等业务弹窗保持优先级。表格/记录的独立搜索与分页只影响该视图，不截断原数据和导出。

## AI 分类与问答结果

AI 设置分为连接与模型、直播感知、知识与搜索、观众与研究、问答测试、本地与性能、高级设置。模型连接不再混入设备准备和观众资料；本地设置进一步分为回复/识别选择、设备准备、额度/时限三组。所有原配置字段仅保留一份，跨分类切换保留草稿与密钥，错误仍可定位所属分类。

问答测试以“本次最终答案”为首要输出，问题、用量、实际处理链路、来源和检查分区展示。历史回答折叠归档，批量场景默认折叠。链路直接来自测试服务已发生的上下文准备、模型调用、意图识别、搜索或缓存、结果检查、完成/失败/取消事件，显示开始后的实际耗时，不伪造模型内部思考或未执行步骤。进行中可查看已发生的步骤；最终答案保持纯文本与导出边界。观众答案正文不含来源角标，不播报本地/联网回答、接口或搜索失败；查到直接回答，没查到自然说明具体未知。来源依据使用独立 citationIndices 元数据核对，结构化 sources 和旧式中英文编号均兼容；搜索、有效缓存、后台研究与评测共用这一边界。原始故障、资料来源及实际使用标记仅在测试/诊断区展示，不拼回公屏正文。

短窗口压缩工具栏，二级页签以单行横向滚动显示；导航、分区选择器和消息可滚动访问。紧凑/滚动模式的状态区最高为控件高度加 12px。尺寸判断以浮窗内容区为准，不依赖网页视口宽高。

不按内容高度重新排序业务数据，不将字段分配到多个状态容器；仅由 Masonry 管理卡片定位。

修改后至少检查：标准一页展示、紧凑一页展示、紧凑后滚动三种结果；窗口变大恢复标准；自然高度、列宽、卡片无交叠、统一间距、横向溢出；长文本、展开详情、空状态和有数据图表；草稿、焦点与滚动位置在重新测量后仍保留；放大视图编辑同步、Escape/焦点恢复、数据更新和小窗口滚动。测量和截图保存到当次任务证据目录。

## 侧栏与 Liquid Glass 基础材质

桌面侧栏展开宽 184px、折叠宽 64px，按钮为 40px 点击区域。图标与标签使用明确的内部网格；折叠时图标居中、完整名称留在可访问标签与悬停提示中，折叠按钮遵循同一规则。660px 及以下改为可滚动功能菜单，恢复完整标签。左右位置与折叠状态只由原导航控制器保存，展示层订阅其变化。

默认材质使用 Liquid Glass；已保存的原始玻璃 / 实色选择继续生效。实现唯一来源为 src/ui/liquid-glass.js：外窗背景使用本地 SVG 位移图折射与磨砂，高光、卡片、输入框共享材质变量；文字和图表不进入滤镜。只保留一个背景模糊层，无远程资源或逐卡片鼠标监听。上游参考与许可见 vendor/liquid-glass-react。减少透明度、强制颜色及不支持背景滤镜的环境使用降级样式。
