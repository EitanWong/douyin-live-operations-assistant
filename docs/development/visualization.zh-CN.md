# 直播数据可视化

PK 局势看板使用 Apache ECharts 6，按需打包折线图、条形图、图例、提示和 SVG 渲染器；扩展和用户脚本均内置代码，不从 CDN 加载图表。扩展目录和 dist 根目录包含第三方许可文件。现有 Solid Glass 面板的主题变量控制图表颜色。

## 图表与数据

- 比分趋势：双方官方累计比分，己方实线、对方虚线；支持 1 分钟、3 分钟、本场全部。
- 分差趋势：仅在双方比分已观测时计算；零线代表平分。
- 贡献榜：双方已观测 PK 贡献分合并取前八；礼物钻石不能替代 PK 贡献分。
- 直播活动：本页最近十分钟的弹幕、进场和礼物件数，每十秒汇总；同时列出点赞、已知钻石及单价未知数量。暂停自动回复仍采集。

图表保留未知比分的空值，不补零。PK 趋势有界保存，时间窗口保留窗口前的最后基线；活动数据保留十分钟。连击按累计数量的增量计件。渲染间隔至少 750ms，隐藏面板或切离 PK 页时不更新图表，销毁面板时释放图表和观察器。失败时保留数据表和提示。

比分通过独立解析通道接收，避免普通互动的存储等待阻塞；双方更新时间分别记录。超过十五秒未更新降低置信度，超过六十秒保持未知；零秒倒计时等待正式终局。局势分析使用已观测分差、近窗速度与剩余时间，不能保证预测准确率，也不能推断未收到的对手弹幕、资金或未知加成。协议证据和限制见 [PK 协议核对](../research/pk-protocol.zh-CN.md)。

## 开发与验证

`src/ui/live-charts.js` 提供纯配置生成器和图表生命周期，`src/runtime/live-metrics.js` 提供活动分桶。`npm run build` 生成扩展、用户脚本及本地演示所需的 ESM 图表包；之后运行 `npm run demo`，点击“模拟 PK 追分局 / 模拟终局”。演示仅生成本地样例。

`npm test` 覆盖协议、时序、数据新鲜度、快通道、未知值、礼物连击和图表配置。真实房间验收步骤见 [本机扩展实测](../guides/live-testing.zh-CN.md)。
