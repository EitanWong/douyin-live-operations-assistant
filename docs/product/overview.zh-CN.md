# 产品范围

抖音直播运营助手服务于直播间管理员、场控和主播团队，在浏览器内处理观众互动与直播配置。

## 当前能力

| 类别 | 内容 |
| --- | --- |
| 互动 | 礼物感谢、连击合并、条件欢迎、点赞感谢、关键词回复、定时消息 |
| AI | Chat Completions 兼容服务、上下文回复、模块话术生成、本地预设回退 |
| 机器人 | @当前账号触发菜单与指令，房间级游戏会话、超时和失败结束 |
| 统计 | 按直播间配置、按北京时间记录礼物日/月汇总、收入估算与导出 |
| 运行 | 优先级队列、可重试发送、持久日志、状态快照和刷新恢复 |
| 配置 | 集中功能开关、独立主播配置、身份识别、连接诊断和导入导出 |

## 交互规则

- 直播互动与设置分组；设置入口始终可访问，互动模块按开关显示。
- AI 服务启用后，互动模块提供 AI 生成选项；不可用时回退至预设。
- 默认发送模式为自动发送，安装后由用户开始，也可按主播启用自动开始。预览模式只生成预览。
- 礼物优先调度，游戏和其他互动共享队列；游戏参与消息与礼物处理可以并行推进。
- 手动暂停清空互动任务和游戏现场；页面刷新保存续跑意图与可恢复状态。

## 范围

当前围绕非电商直播互动。PK 战况、跨房间分析、胜率模型和道具概率预测属于后续方向，尚未实现。管理员身份按房间返回资料核验，自动封禁和禁言尚未实现。

收入默认按 0.05 元/钻估算，可按主播调整；统计覆盖工具采集的时段，平台实收以结算单为准。

功能及恢复行为已经过自动化测试，真实平台字段、编辑器发送、公屏回显及长时间实播仍按[实测流程](../guides/live-testing.zh-CN.md)验收。
