# 产品范围

抖音直播运营助手服务于主播、直播间管理员和场控团队，在 Chrome / Edge 中管理网页直播互动及已采集的直播数据。当前版本为 **0.1.3**；安装与首次操作以 [项目首页](../../README.md) 为准。

## 当前能力

| 类别 | 内容 |
| --- | --- |
| 互动 | 礼物感谢、连击合并、条件欢迎、点赞感谢、关键词回复、多组定时消息 |
| AI | 兼容接口、本地文字与语音、共享现场语境、知识检索、联网查证、观众记忆、问答测试与预设回退 |
| 直播感知 | 按需接入直播音轨和画面，可选原生组件；本地视觉尚未实现 |
| 观众工具 | 四种房间游戏、多奖品加权抽奖、福袋红包自动参与、自动点赞、预算受限的自动送礼 |
| 统计 | 礼物账本、收入估算、场次与月度汇总、PK、段位、任务与展馆、预测及多维图表、导出 |
| 管理 | 内容治理、权限核验、多主播独立配置、连接诊断、配置导入导出 |
| 运行 | 等待开播与持续监控、优先级队列、持久日志、状态快照、失败隔离和刷新恢复 |
| 工作台 | 统一侧栏与工具入口、拖动缩放、主题、等高卡片、有界正文和独立放大 |

## 交互规则

- 默认发送模式为自动发送，需用户开始或为主播明确启用自动开始；首次配置建议先选择“仅预览，不发送”。
- 礼物优先调度，游戏及其他互动共享队列；手动暂停停止场控任务，可恢复状态按运行规则保存。
- 自动送礼是独立工具，真实消耗钻石，需要单独手动开始，不受场控预览模式保护；刷新不续送。
- 禁言和直播间封禁需要当前账号为主播或管理员，并以平台实际接受结果为准。
- 配置草稿由原控制器管理，统一工作台展示；切页、缩放与展开不会自行保存草稿。

## 数据边界

收入默认按 0.05 元/钻估算，可按主播调整；统计只覆盖工具采集时段，不能还原未观察的直播。预测属于模型参考，缺失数据保持未知，平台实收以结算单为准。

本地功能依赖设备与浏览器能力；云端 AI、搜索和媒体识别会按配置传输相关上下文至所选服务。可选原生自动安装支持 macOS / Linux。平台字段、权限、发送回显与长期运行按 [实测流程](../guides/live-testing.zh-CN.md) 验收，自动化测试不代替真实平台结果。
