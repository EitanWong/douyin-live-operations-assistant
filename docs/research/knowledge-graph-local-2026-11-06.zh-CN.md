# 可视化知识图谱与本机自动知识库

本轮复用本机独立数据组件。浏览器后台是有效知识和遗忘版本的唯一写入者；原始档案可重建人物关系索引，SQLite提供独立的中文全文查询。无需新增云端数据库、向量服务或按条付费的关系抽取。

## 成熟组件选择

| 项目 | 本轮采用范围 / 取舍 |
| --- | --- |
| [Apache ECharts](https://github.com/apache/echarts) · Apache-2.0 | 使用已安装的GraphChart、力导向布局、拖动、缩放、邻接强调、SVG与无障碍描述，接入全工作台统一图表和放大弹窗。 |
| [Cytoscape.js](https://github.com/cytoscape/cytoscape.js) · MIT | 对照图分析能力；现有有界浏览与两跳检索不需要第二套可视化运行时，暂不引入。 |
| [LightRAG](https://github.com/HKUDS/LightRAG) | 参考原文、图谱与检索分离的思路；没有部署该服务或声称已接入其自动LLM图抽取。 |
| [RAGFlow](https://github.com/infiniflow/ragflow) | 对照专业知识库的来源管理与检索工作流；其额外容器、资源及模型依赖不适合当前本机成本目标，暂不部署。 |
| SQLite FTS5、MiniSearch | 前者运行于已存在的独立原生组件，后者用于浏览器中文分词、双字词与BM25背景检索；均不调用模型。 |

## 用户路径

1. 重载更新后的`dist/chrome-extension`。在“AI设置 → 观众与研究”启用持续记忆、公开资料自动更新及“自动研究主播和重点观众”，保存设置。
2. 直播页存活时，已观察的主播/观众账号按既有门槛进入候选。公开评论、回复中的稳定secUID还可扩展两层，深度随记录持久保存。昵称不用于搜索绑定身份，冲突UID/secUID不扩展。
3. 任务共用已有串行队列、每小时额度、冷却和每轮候选上限。最久未尝试的合格来源先刷新，避免前排账号长期占满预算。登录、验证、无权限、页面没有实际加载的内容保持未知。
4. “知识库 → 人物关系图谱”打开时自动浏览；可拖节点、滚轮缩放、点选节点/连线查看证据，也可用下拉列表键盘选择。角标打开统一放大弹窗。可按人名查询、按可信状态筛选并导出当前图谱JSON。
5. 图谱可见且展开时每10秒更新，隐藏时不刷新；不变的证据复用图表配置，保留查询与选中项。普通正文滚动和放大弹窗承接长内容，图表高度来自共享布局。
6. 常规问答的真实搜索原文、后台研究成功读取的公开原文自动写入后台知识库，去重保存。联网知识列表可查原文、删除或清空。模型的回答与推断不成为已核实事实。

## 持续更新方式

图谱从持久证据重建：新增对话和公开原文进入原有采集、去重、来源校验与检索链路后，下一次查询自动纳入人物和关系；相反陈述并存时标记冲突，删除和过期资料退出有效图谱。AI回答和研究会使用最新相关关系与原文，研究成功读取的新来源继续沉淀，形成持续积累的回路。图谱可见时每10秒反映这一变化，关闭图谱不影响原有采集和记忆写入。

绘图、布局、缩放和交互由ECharts GraphChart承担，持久化/全文索引分别复用Dexie与SQLite FTS5，背景检索使用MiniSearch。项目代码只负责账号身份、来源可信状态和业务证据适配。持续完善的对象是资料、关系与证据覆盖；本轮没有自动训练模型权重，也不会将模型猜测升为已核实关系。中文关系结构化目前覆盖明确陈述，其他内容保留原文供问答检索。

## 数据和证据边界

- 手工核实知识、公开资料、弹幕自述、协议互动分别保留来源、时间和可信状态。`verified`是运营核实；`unverified`是未核实陈述；`observed`是观测到的互动；`conflicted`须同时呈现相反证据。回复或提及不等于朋友、师徒、亲属。
- 图谱按房间/主播保存证据范围，只有无冲突稳定账号配对可跨范围连接。同名提及不会自动合并，关联路径不会推导两端存在直接私人关系；画面不认证人物身份。
- 自动原文每个房间/主播最多1000条、总正文40万字，单来源最多12000字；SHA-256按规范URL和正文去重，超限保留较新资料。实时查询沿用2分钟、规则1天、稳定背景7天的时效，重复复用不重置原采集时间。
- 当前账号资料24小时；作品/评论/弹幕等历史采样沿用180天、3000条上限。旧作品只作带日期背景。采样不是读取全部主页、视频、弹幕或互联网关系。
- 普通图谱概览最多80个人物、100条关系；完整来源仍可按人检索。问答按已有上下文预算选取相关关系与原文片段，生成后复查，删除期间的旧答案作废。
- 删除/清空立即移除浏览器有效证据，并提升遗忘版本，使旧任务无法回填。短期缓存须再次确认原文仍在后台有效库；本机同步失败保留待同步版本，重启后幂等重试。缓冲失败也不阻止浏览器先忘记。

## 独立本机服务

已有用户启用的本地归档设置保持原样。启用后，自动原文增量及删除水位经原有持久outbox写入SQLite，与原始审计档案独立维护有效来源索引；未启用时后台IndexedDB知识仍可使用，不会强制开始本地归档。关闭归档期间不补录旧增量；开启后新采集来源参与同步。

更新已安装的数据组件：

```sh
npm run data:install -- --extension-id=你的扩展ID
python3 native/data_host.py knowledge --room 直播间ID --anchor 主播UID --query '阿明'
```

独立服务采用FTS5中文单字/双字索引、绑定参数查询，返回最多8条有效原文，保留来源URL、原采集时间、到期时间和待核实状态。索引按房间/主播隔离，事务失败整批回滚，旧同步序号不能覆盖新删除水位。原始追加审计档案通过既有export/backup管理，不自动作为AI的有效记忆重新灌入。关闭归档时积压仍保留，删除同步在恢复归档后生效；外部CLI查询不代替浏览器当前记忆开关。

任务只在Chrome和直播页运行时自动发现、采集账号；后台研究任务由扩展宿主持久执行。没有新建常驻爬虫守护进程，也没有绕过平台登录/验证、无限遍历账号或完整互联网爬取。真实抖音账号端到端和全天运行仍需单独验证。
