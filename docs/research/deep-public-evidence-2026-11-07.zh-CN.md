# 深度公开研究：增量作品与证据归属

本轮在已有 LangGraph、Dexie、Zod、MiniSearch、LinkeDOM 和 Readability 上增强检索与人物研究，没有增加第二套 Agent、人物数据库或下载签名实现。原始记录与派生检索保持分离；公开账号、发言人、作品作者和画面人物不能互相替代。

## 已交付行为

- 搜索客户端接受博查 `datePublished`、Tavily `published_date`、SearXNG `publishedDate`；用 LinkeDOM 提取摘要与标题文字，移除脚本、样式等非正文，忽略非字符串摘要字段。超过 2000 字符的来源 URL 整条排除，避免截断后指向另一份资料。
- 新研究步骤对同一 URL 使用同一引用编号。读取正文原位替换摘要；后续摘要不能覆盖已读取正文。互补检索片段合并，保留最早采集时间和最短有效期，不用追加查询给旧片段续期。每份正文仍最多 6000 字符，研究工作集仍最多 6500 JSON 字符。
- 来源目录与浏览器原文库保留发布时间、证据种类和覆盖声明，重启与前台按原文片段复核时继续携带。发布时间与采集时间分开，所有来源仍是待核实材料。原生通用 FTS 沿用现有正文索引，附加元数据保留在原始归档中，不宣称原生查询接口新增了这些字段。
- 公开主页每轮仍最多顺序访问两部原页面已经加载、作者匹配且链接与作品 ID 一致的作品。先处理未采样作品，再复查已满一天的旧作品；失败至少退避 15 分钟。已成功页面采样不等于整部视频分析完成。
- 进度由后台既有串行采集队列单写，按房间与主播隔离、主页分别记录，归档确认后才提交进度。重启可继续访问尚未完成的可见作品；取消、切主播、归档失败不确认进度。每主播范围最多 100 个主页、每主页 200 个作品状态，保留至多 180 天；进度没有正文或模型推断。
- 作品资料进入模型前按问题用 MiniSearch 选择相关原记录，保存可解析 JSON，最多 6000 字符。原话与发言账号、作品 ID、语音/画面模态、片段位置和覆盖声明一起提供；评论作者不是主页作者，未认证语音保持“说话人未确认”，视觉识别保持待核实。完整可用原始记录仍在既有归档。

这些改动改善资料流与可核对性，不等于测得真实模型准确率提高，也不保证所有作品、每条评论或每位观众的终身记忆。原有授权、来源开关、研究额度、遗忘版本和发送边界继续由原控制器管理。本轮没有启用用户开关或发送真实弹幕。

## 后续交付与验收门槛

下一步是本机公开视频任务的“作者核对 → 下载 → 字幕/完整音轨转写 → 时间轴关键帧 → 原文证据入库 → 按人问答 → 取消/遗忘”闭环。先确定现有原生 ASR 单实例的资源租约与任务持久化边界，再接下载适配器；直播识别应优先，不能后台另开模型争用。不能把失败、部分采样、配音或评论转成作者的心理特征或真实经历。

必须通过一个可访问公开作品的实际端到端验收，再扩大批量：保存下载来源与作者、内容哈希、分析器版本、完整/缺失时间区间；失败可重试，取消与遗忘后迟到结果不回写。还需真实模型事实性/引用评测、长期资源竞争与实播验收。当前缺少配置的真实模型评测环境变量，本轮使用合成服务验证协议与业务行为。

执行动作、完整测试和推送结果见[行动日志](../development/action-log.zh-CN.md)。本机原始证据保存在 `output/deep-research-2026-11-07/`，其中包含失败轮次，不能将所有记录计为通过。

## 本机公开视频队列与完整音轨处理阶段

新增 `native/public_media_jobs.py` 与 `native/public_media_worker.py`，使用原归档 SQLite，不建立第二份人物库。任务按房间、主播、稳定主体、遗忘版本、作品 ID、作者 secUID 和分析版本去重。全库只有一个运行任务，待处理上限 32，租约 60 秒、每 10 秒续约，意外中断及下载失败有有界恢复/退避。取消阻断迟到写入；遗忘递增版本、删除证据和媒体哈希并清零游标。迁移仍由原 DataLocation 决定，每次数据库操作短暂取锁，下载与推理不阻塞归档搬迁。

下载复用固定 `yt-dlp==2026.10.26`，隔离用户配置/插件，无 Cookie 导出或挑战绕过。下载前后均核对作品 ID、作者 secUID、主体 UID/secUID、Douyin 提取器与时长；只接受规范作品链接，限制文件 256MiB、时长 3 小时。媒体临时保存，任务结束清理。转录前绑定 SHA-256；重下载内容变化会删除旧片段并从零开始，不能将两份文件拼接。FFmpeg 输出 16kHz 单声道 PCM，按 4 秒块转录和持久化，静音仍记时间覆盖；检查解码退出状态、连续区间及与元数据的时长差。音轨完整只表示解码和时间覆盖完整，**不表示转录准确率、视觉分析或视频作者发言身份已验证**。

共享 SenseVoice 通过操作系统文件锁控制模型所有权；直播意图优先，后台准备/推理边界或每秒监督时让出，下载也可中止。取消时等待正在执行的 Python 推理线程结束再卸载模型，结束下载/FFmpeg 进程组并排空管道。模型安装诊断显式释放资源。旧版已运行原生宿主不会参与新锁，本轮没有升级或重启用户正在使用的宿主，因此不能据此宣称已安装的实时环境具备上述互斥保证。

持久 API 已加入数据宿主 `public-media` 的 submit/list/get/cancel/forget/evidence 操作，隐藏工作者租约；证据每页最多 8 条，最大 Unicode 正文也能通过原生消息 64KiB 出站限制。本机感知安装快照包含工作者及其归档依赖，可用该快照的 `.venv/bin/python public_media_worker.py --once` 运行一次或去掉 `--once` 持续检查待处理任务，读取同目录 runtime.json。**浏览器尚未提交/调度该类任务，也未同步遗忘版本和将新转录接入原文库检索；此命令目前供开发验收，不能替代产品已接通。**

实际下载上游公开测试作品 `6961737553342991651` 返回 HTTP 403，yt-dlp 报 `Fresh cookies (not necessarily logged in) are needed`。本轮未获取 Cookie、未绕过验证，也没有将失败作品标为成功。实际平台全片验收仍未通过。使用真实 FFmpeg 的合成音轨验证全音轨、静音、截断、取消、抢占和迁移；ASR 使用可控替身验证归属与生命周期，未声称真实模型转录质量已验收。检测到旧版本机宿主正在运行，未并发加载第二份真实模型。

下一阶段先完成受现有设置与遗忘版本约束的浏览器桥，再接时间轴视觉采样和既有原文知识库。需要一个当前可访问作品贯通真实下载、真实 ASR/视觉、检索和按人问答，最后做真实模型引用/事实性与长期实播验收。商业级准确率目前没有验收结论。

浏览器桥接的源码复核：`createAccountResearch` 是串行采集与额度的唯一入口，`createKnowledgeCorpus` 是原文入库的唯一入口。观众遗忘版本由 `subjectEpoch` 的 `forgetBefore`/`forgotten.at` 时间戳决定，不能直接用本机队列的“当前版本加一”替代；后续桥须把浏览器权威版本单调同步到原生，并在归档与检索返回前复核 `checkResearchProfile` 的稳定账号配对及版本。不得另建一套人物版本或只按昵称提交任务。


## 浏览器桥接与主播资料入库阶段

上节“浏览器尚未接通”描述的是前一阶段。本阶段账号采集成功后会通过独立原生端口提交稳定身份对应的公开作品，启动既有队列工作者，并在启动、原每分钟 alarm、配置或遗忘变化时同步/恢复。仅在原 AI、人物记忆、账号采集、本地音轨/音画和归档设置允许时工作；能力探测本身不加载模型，旧宿主不支持 publicMedia/modelLease 时拒绝启动。已知旧版实时 ASR 所有者未确认租约协议时也阻止新的后台模型。产品源码已经接通，但本机正在运行的旧宿主未升级，本轮未做已部署浏览器实际验收。

浏览器遗忘时间戳是唯一权威版本。原生新增 scopes/sync/reconcile/ack：全 scope 分页、全历史主体事务删除、原样版本同步、每页八条导入确认。知识清空版本进入任务身份；缺失 canonical memory 清除原生证据，重新打开开关不自动复活取消任务。已完成音轨以原 JSON 片段进入同一知识库，记录作者、主体、哈希、分析器版本和时间区间，语音说话人仍 unknown。没有视觉结果的任务明确标注“视频画面未分析”，音轨时间覆盖完整不代表音画内容完全理解。

共享 researchSubject 将既有房间主播 profile（稳定 UID/secUID 与更新时间）接入同一遗忘时钟，使主播无需发弹幕也能参与研究和原文检索。冲突配对和遗忘前观测不参与；原文来源保留主体。观众询问主播时可以使用本房当前主播的原文，不开放其他观众的个人资料；引用待核实原文不能证明视频声音属于作品作者。

集成测试实际经过 native framing、SQLite、FFmpeg、持久原文库和前台检索/引用，覆盖观众与无弹幕主播、ack 中断重试、重启去重与历史遗忘；下载、ASR、模型回答是受控夹具。原生全测 86/86；本阶段其余最终回归和推送结果见行动日志。真实平台 403、真实模型准确率、时间轴视觉分析和长期资源/实播验收仍未完成，持续目标保持 active。
