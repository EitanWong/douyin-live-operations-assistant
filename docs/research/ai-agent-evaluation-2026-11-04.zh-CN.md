# AI互动回复与完整Agent评测（2026-11-04）

采用MIT开源[Promptfoo](https://github.com/promptfoo/promptfoo) 0.125.1，通过用户授权的百炼业务空间调用Qwen `qwen3.8-omni-flash`。密钥仅经进程环境传递，未写入仓库、配置、任务或报告。

## 范围与判定

45项场景包括36项真实模型、4项无需调用模型的门控和5项可复现故障注入。每项连续执行两次、不缓存答案，逐项保留原答与检查结果；模型不知道评分答案。全部检查通过才算该次通过，任何失败使命令非零退出。脚本位于`scripts/evals/`，可运行`npm run eval:agent -- --repeat 2`，配置方法见[AI上下文指南](../guides/ai-context.zh-CN.md)。

前台链路为真实Engine事件入口→共享上下文→云端韧性层→意图路由→搜索客户端/IndexedDB来源缓存→回答→队列→公屏格式/时效检查→preview。后台链路为createLocalAgentTasks→XState AgentHarness→任务保存→createResearchAgent→模型/搜索→带来源结果。所有测试均禁止实际弹幕发送。

| 类型 | 检查内容 |
| --- | --- |
| 问答事实 | 天气城市/日期/温度/来源、追问指代、普通常识、错误前提、矛盾与部分资料 |
| 数值边界 | 精确十进制、负数、大小/相等、除零、零与缺失、旧账本不当当前值 |
| 抗干扰 | 网页指令注入、长背景、来源末尾事实、不编商品价格/颜色 |
| 语音接话 | 同期音画的主播邀请、重复识别去重；背景电视、自言自语保持静默 |
| 架构 | 关闭AI、仅@、他人对话、额度、重复事件、取消、迟到结果、缓存复用 |
| 故障 | 401、非法意图、超长输出、关闭时取消到底层、不复活旧任务 |
| 后台研究 | 来源事实、任务持久保存、重复提交幂等、密钥不保存、结果不发公屏 |

## 发现与修复

- 实时查询零有效来源时，产品层仅输出具体查询主题、故障类别和重试建议，不允许模型猜测天气；稳定常识继续回答。此项评测验证产品交付，不能解释为模型本体已掌握实时预报。
- 缺引用不能覆盖正常正文；引用编号由模型选择、程序校验，不伪造来源。空结果/搜索故障继续生成有用的具体答复，实时数据无依据不猜。
- 查证阶段去掉接话、技能和支持者画像的干扰，只保留问题、必要上下文及来源；为引用预留字数，非法结构化数组不成为弹幕。
- 数学采用有界精确十进制工具，支持@弹幕，先在chat分支采用工具结果再检查长度。超长精确结果明确提示拆分。
- 过期本场账本的当前金额投影为未知，原账本不改；不依赖模型一边看到旧数字一边遵守stale说明。历史通过独立有日期字段读取。
- 语音意图使用专用精简任务，按同期音画和对话归属判断；所有意图路由关闭聊天采样，事实回答保留用户温度。
- 端侧关闭时云端使用总预算，保留总截止及底层取消；端侧启用时保留原竞速预算。
- 评分误判先补正确/错误对照再修，未放宽天气数值、资料依据或不编造标准。音画fixture按真实重叠时间区间构造，背景声仍必须静默。
