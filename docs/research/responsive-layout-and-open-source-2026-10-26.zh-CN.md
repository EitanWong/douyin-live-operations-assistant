# 面板响应式布局与开源参考

日期：2026-10-26。

## 发现的问题

- 默认悬浮面板固定为 620px，在桌面浏览器中也只能看到较长的单列页面。
- 多栏要等内容容器达到 800px 才启用；侧栏占用 172px 后，中等窗口很容易退回单列。
- AI 的问答、资料与搜索放在同一列，服务连接列较短，左右高度失衡。
- 主播页新增的最高单价礼物、贡献榜播报等区域没有统一分组；趋势区域跨行导致邻列留下空洞。
- 部分组件根据浏览器视口判断窄屏，不能准确反映桌面上的窄悬浮面板；短窗口图表规则曾查询仅支持宽度的容器。

## 开源项目核对

本次查阅项目 README、官方文档及响应式示例，提取布局方式，未引入以下项目的运行时依赖。

| 项目 | 已核对资料 | 对本项目的启发 | 采用方式 |
| --- | --- | --- | --- |
| [Tabler](https://github.com/tabler/tabler) | [README](https://github.com/tabler/tabler/blob/dev/README.md)、[Page layouts](https://docs.tabler.io/ui/layout/page-layouts) | 管理台导航、内容容器、同行区块与整行内容应分层组织 | 保留现有导航，将独立设置任务作为 Grid 同级区块；榜单与词库使用整行空间 |
| [GridStack](https://github.com/gridstack/gridstack.js) | [响应式示例源码](https://github.com/gridstack/gridstack.js/blob/master/demo/responsive.html) 的 `columnOpts.columnWidth` | 列数应由实际可用宽度和内容需要决定 | 使用命名容器查询，按面板内容宽度分栏，避免依赖整个直播网页的宽度 |
| [React Grid Layout](https://github.com/react-grid-layout/react-grid-layout) | [README](https://github.com/react-grid-layout/react-grid-layout/blob/master/README.md) 的响应式布局与断点说明 | 不同断点需要明确的布局关系 | 为窄、中、宽内容区提供明确列数；表单 DOM 不随断点重建 |

GridStack 与 React Grid Layout 适用于需要拖动卡片、保存用户自定义布局的场景。当前需求是稳定的运营工具布局，现有 CSS Grid、ResizeObserver 与原生 details 已能实现，采用这些布局原则即可。

## 落地规则

所有断点均为面板内容容器宽度，已扣除导航所占空间。

| 内容宽度 | 布局 |
| --- | --- |
| 小于 720px | 单列阅读；次要分析默认折叠；保持表单内容和用户手动展开选择 |
| 720px 起 | PK 图表、主播分析、独立设置任务使用双列；窄列内的成组输入继续根据列宽退为单列 |
| 900px 起 | 主播核心指标与礼物指标并排显示，减少顶部纵向占用 |
| 1100px 起 | 功能开关、主播状态使用三列；展馆与 PK 明细按内容需要跨列 |

- 首次打开或恢复默认大小时，面板宽度取浏览器宽度的 78%，目标宽度限制为 620–1280px，最终受视口边界约束。用户已保存的手动尺寸仍优先。
- 主播筛选与时间概览同行，图表同行，最高单价礼物与贡献榜播报同行；移除趋势图固定跨两行的规则。
- AI 将服务连接与共享上下文放在一侧，联网搜索放在另一侧；问答与场控资料在下一行独立分栏。
- 礼物数据与近期礼物同行，门槛设置与感谢话术同行；欢迎、点赞感谢、机器人、外观和诊断按任务分组。
- 内容治理将检测范围与分级处置并排，检测词库占整行并在内部双列排列。
- 表格和长趋势保留局部滚动；页面容器和 Grid 子项允许收缩，避免整页横向溢出。
- 短窗口图表改用支持尺寸查询的 `assistant` 容器。

## 验证范围

- 完整自动化测试 702 项通过；布局行为覆盖 719/720px 边界、手动展开偏好、聚焦输入保护、键盘缩放及恢复默认尺寸。
- Chromium 实际渲染检查覆盖窄悬浮面板、中等窗口、侧栏布局、桌面视口、手机尺寸视口与横向短窗口；用真实页面文案和本地模拟数据检查各功能页。
- 检查组件是否超出页面边界，表格内部滚动不作为页面溢出；同时查看顶部及滚动后的截图。
- `npm run check`、`npm run build` 验证源码、独立油猴脚本及 Manifest V3 扩展产物。
- 验证基于桌面 Chromium 与视口模拟，不包含物理触屏设备或 Safari 实测。

临时截图及测量结果位于忽略目录 `output/playwright/`。
