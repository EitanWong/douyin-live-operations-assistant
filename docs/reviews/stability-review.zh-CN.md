# 稳定性代码审查与修复

本文保留各轮修复记录及当时的测试结果。当前验证状态见[验证记录](validation.zh-CN.md)，最新运行时重构见[性能审查](performance-review.zh-CN.md)。

## 2026-10-16 刷新与崩溃恢复

- 引擎快照按直播间保存运行/续跑意图、游戏会话、礼物连击进度、待发送队列、去重记录、冷却和定时任务。页面卸载释放 Web Lock，但保留续跑标记；重载后等连接与锁就绪再恢复。
- Chrome 扩展为运行中的事件增加持久日志。事件先写入扩展本地存储，再交给引擎；引擎快照成功后才确认删除日志。重启先按顺序回放未确认事件，再放行实时事件；暂时存储错误会串行退避重试。
- 自动发送前强制落盘在途任务。刷新发生在点击确认之间时，按 at-least-once 恢复，极少数情况下可能重复；网页端没有服务端幂等键或发送回执，无法实现真正 exactly-once。
- 事件日志覆盖事件到达扩展隔离世界之后的故障窗口。抖音页面主世界到隔离世界交接前的渲染进程崩溃、网络断开期间平台未重放的事件、浏览器数据被清除或持久存储不可用，仍无法由本地扩展补回。存储不可用时事件交接重试，发送前检查快照持久化，避免把未持久化状态报告为成功。
- 回归验证包括后台重启后读取未确认日志、房间隔离、短暂存储失败重试、运行快照先于事件确认、游戏和连击恢复、发送中刷新及事件处理顺序。

## 2026-10-16 礼物遗漏与开发更新

本轮沿数据接收、协议解析、页面握手、去重和持久入账逐层检查，修复以下可复现路径：

- 删除等待解析超过 100 帧时直接丢帧的逻辑，按顺序处理并分批让出主线程；单条消息或订阅回调异常不再截断其他礼物。
- 页面主世界与内容脚本握手完成前保留礼物，避免初始化过程中超过 100 条被截断。
- 礼物类型改读 `GiftStruct.type` 字段 11；显式零分组视为无分组，独立礼物不再共用零分组。数量增加字段 44 的后备读取。
- 账本保留已结束与被活跃缓存挤出的连击进度；结束后到达的更大累计数只补增量，后来补到的单价回填原日期。旧版只保存 true 的已结束记录继续保留原去重语义。
- 同一消息 ID 的数量、单价或结束状态更新仍可参与互动结算。账本容纳近十分钟服务端延迟，按进入存储队列时的时间校验，磁盘写入排队不会把已收到礼物变成过期事件。

加入 `npm run dev`：监听源码、串行构建、构建成功后通知扩展重载和直播页刷新。重载前等待后台已接收礼物的写入；刷新交接用 `storage.local`，因为 `storage.session` 会在扩展重载时清空。开发专用端口仅绑定 127.0.0.1 并返回构建标识；正式构建没有该通道和权限。

回归覆盖 160 帧高峰、握手前 160 条礼物、1200 条礼物突发、单条损坏消息、零分组、乱序连击、结束后补价、缓存挤出、服务线程重启、写入排队，以及开发更新失败重试与页面刷新交接。现有配置和账本无需清除。过去没有采集到的历史礼物无法从本地账本恢复，自动刷新期间也不承诺持续采集；真实直播准确性仍需对照实测。

日期：2026-10-15。针对单页被误判为多页占用、误暂停、键盘误触发，审查运行锁、所有停止入口、连接状态、异步任务、页面生命周期与键盘传播。本轮保持开发版本 0.1.1，不发布或修改版本号。

## 已修复问题

| 问题 | 原因与修复 | 验证 |
| --- | --- | --- |
| P1 本页暂停后提示另一页占用 | Engine 内部发送失败、下播、配置更新直接 stop，绕过应用层的锁释放。统一通过 onStop 释放运行锁，包括正在申请的锁。 | 应用集成测试复现发送失败、下播后重新开始；验证 running 和 held 一致。 |
| P1 连续启停、取消开始的竞态 | 原生锁申请非幂等，释放后旧 callback 可能改写新一轮 held；未取消待完成申请。增加申请代次、共享 pending、等待旧 callback 完全退出；取消后迟到授权立即退还。 | 重复申请、20 轮释放重取、申请前/申请中取消、底层错误后重试。 |
| P1 存储租约误报 | 旧备用路径用本地缓存协调异步 Chrome 存储，10 秒租约还受后台节流影响。使用浏览器原生 Web Locks，不再读写或广播运行租约；旧 lease 数据不参与判断。浏览器负责跨页面互斥及销毁页面后的释放。 | 过期/残留存储不影响；同房间互斥，不同房间独立；真实浏览器两页竞争、接管、关闭占用页。 |
| P1 安静房间/短暂重连误暂停 | 把最近 90 秒没有成功解析的消息当成断线，且 socket 关闭就立即永久暂停。改为以 open/close 状态判断传输；断线期间暂缓发送，恢复后继续。输入准备期间断线也不点击发送。 | 一小时没有帧仍在线、多 socket 中一个关闭、临时断线后恢复；断线发生在填入文本后不提交。 |
| P1 旧发送任务误停新运行 | 暂停重启后，旧 Promise 拒绝仍执行 stop，成功回调仍写新一轮统计。发送完成、失败及外层调度异常均核对运行代次。 | 旧任务分别成功/失败，新一轮保持运行，队列和统计不受污染。 |
| P2 历史下播通知误暂停 | 下播处理早于事件时间检查。先过滤历史/异常时间，再在运行时处理结束事件。 | 31 秒前结束事件被忽略，新结束事件仍正常停止。 |
| P2 键盘事件干扰网页 | Shadow DOM 中的键盘事件会冒泡到宿主页；导航未检查修饰键、输入法和重复按键。隔离面板键盘冒泡，导航忽略这些组合；启停按钮阻止输入法/长按/组合键的默认激活，保留正常键盘操作。 | 自动化与真实浏览器验证；输入框 Enter 不启停，Ctrl+方向键不切页，普通方向键仍切页。 |
| P2 自动发送遗留焦点 | 自动化聚焦直播输入框后不恢复，可能把用户后续按键留在直播页。完成/失败/取消后恢复原有焦点；中途用户自己移走焦点则不争抢；原控件隐藏时解除直播输入焦点。 | 面板 Shadow DOM 焦点恢复、用户移走焦点、断线取消。 |
| P2 浏览器后退返回后失效 | pagehide 一律永久清理定时器和身份读取器，BFCache 返回后没有恢复入口。按 persisted 区分暂存与销毁，返回后恢复观察和刷新；仅离开前仍允许自动开启的页面恢复自动开启。 | pagehide/pageshow persisted 往返后可以重新开始，锁正常释放，手动暂停不会被撤销。 |
| P1 礼物高峰重连后漏发 | 已结算的礼物任务沿用普通消息短过期时间；发送控件暂不可用或连接超过 120 秒时会被清理。礼物感谢任务在成功发送或明确暂停前保留，暂时缺少输入框/发送按钮时指数退避重试；点击后未清空仍停止，避免重复发送。 | 礼物高峰批量、可重试失败、180 秒断线后恢复发送。 |
| P2 主播自动开启误重启 | 自动开启只看配置，手动暂停或 BFCache 返回时可能再次启动。按页面、手动暂停和离开原因记录武装状态；仅连接恢复且本页仍获授权时自动开始。 | 配置开启时等待连接；手动暂停、下播、页面离开后不偷偷重启。 |
| P1 多种礼物文本超长漏发 | 同一观众多种礼物合并后，逐一列名称可能超过字数限制。依次缩短描述、降为总量感谢和简短感谢，避免长文本一直排不进队列。 | 同一观众 30 种礼物、10 字限制下仍完成感谢结算。 |
| P2 低单价过滤忙循环 | 按单价门槛过滤的礼物不再每 500 毫秒重算，等待后续帧或价格更新。发送控件缺失后清理失败时停止，避免把遗留文本当作安全重试。 | 单价过滤、发送缺失/禁用/多候选、退避后仅成功发送一次。 |

## 验证证据与边界

- `npm run build` 后运行 `npm test`：148 项通过，0 失败；`npm run check` 与 `git diff --check` 通过。
- 独立 Chromium 浏览器的本地模拟器：两页竞争时仅一页能运行；暂停后另一页接管；连续 15 次启停正常；关闭持锁页后原页可以开始。使用真实 Web Locks API，不依赖租约模拟。
- 同一浏览器中，面板输入框的 Enter、空格、方向键向 document 冒泡次数为 0；Ctrl+右方向键未切页，普通右方向键切换正常，输入框 Enter 没有开始场控。该隔离针对冒泡阶段，不声明能屏蔽宿主页已注册的捕获阶段监听。
- Chrome/Edge 新版的 HTTPS 页面和 localhost 支持 Web Locks。缺失 API 时明确提示浏览器不支持，不再把底层错误报告为另一页占用。运行权按浏览器存储范围协调，不跨独立浏览器或独立用户配置文件。
- 发送失败、手动草稿、控件重绘和结果未知只记录状态并保留任务，场控不会因此自动暂停；只有用户明确点击暂停才停止。页面刷新、离开或切换直播间属于浏览器生命周期处理，运行快照会保留待恢复任务。
- 本轮没有向真实抖音直播间发送弹幕。真实平台发送、长期休眠和长时间实播稳定性仍需实测。

## 加载本机修复版

在 `chrome://extensions` 中重新加载当前项目的 `dist/chrome-extension`，随后刷新直播页再开始。只刷新模拟器不会更新已加载的扩展内容脚本。无需清除配置、账本或其他本地数据。
