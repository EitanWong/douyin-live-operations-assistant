# 运行基础与开发索引优化

环境：macOS arm64、Node v26.12.1、锁定依赖。机器可读结果见 [基准数据](foundation-benchmarks-2026-11-05.json)。功能修复遵循先红后绿；完整过程和最终交付回执见 [行动日志](../development/action-log.zh-CN.md)。

## 可检查的改变

- Inbox 在每200条或8ms的事件间隙让出执行权，仍是单消费者、按序处理，保留背压、隔离与日志重放的一条步进。最终关闭清空积压和隔离引用，迟到处理不再更新计数或状态。600条突发测试中主线程计时器在排空前执行，600条仍全部完成。
- 界面投影删除全页 JSON 签名，以结构共享保留相同分支；React 复用视图节点，格式函数按身份更新。后台页面内部变化不再遍历前台图表。源控件的强引用限于当前投影，销毁释放快照，重新挂回同一控件仍能操作。
- 启动监控在创建面板前建立租约；查询房间接口的耗时不再阻挡保活状态。最终关闭后的查询和检查点不会再读取已经销毁的页面上下文。修改前远端 CI 与本轮初次全测均在未开播租约断言失败；新增确定性回归重现了界面/查询等待问题，没有放宽既有用例的6秒等待。
- 开发索引覆盖414个JavaScript模块、2517个顶层符号及类成员，另含导入、重导出、源码引用、资源调用与测试名称。内容哈希校验检测新增、修改、删除，生成输出确定且原子替换。Acorn只用于开发；索引不打进扩展。命令、导航、术语与局限见 [Agent指南](../development/agent-guide.zh-CN.md)。

## 本地微基准

同一夹具：6张图，每张1000点；预热10轮，测100轮。修改前在任务起始保存，修改后在完整回归结束后单独运行。它比较的是DOM投影与对象保留，未模拟浏览器图表绘制。

| 指标 | 修改前 | 修改后 |
| --- | ---: | ---: |
| 100次后台页更新引发的前台图表读取 | 600 | 0 |
| 100次后台页更新总耗时 | 43.409 ms | 1.176 ms |
| 100次纯状态更新替换当前内容快照 | 100 | 0 |
| 单次纯状态更新中位数 | 0.450 ms | 0.465 ms |
| 单次纯状态更新 p95 | 0.726 ms | 0.618 ms |
| 100次更新后GC堆增量 | 734,824 B | 313,368 B |

状态投影中位耗时基本相同；收益主要来自后台更新无需做投影、内容引用不变时无需重新提交图表，以及不再保留序列化副本。堆增量是包含jsdom分配的单次诊断，不是扩展总内存的降幅；毫秒结果和GC采样会随环境浮动，不作为测试门槛。

已有运行基准仍保持：1000次空闲tick为0次changed，1001次快照请求合并为2次实际写入，1200条礼物全部入账并排空。调度算法没有在本轮改动，不把已有算法性能归功于本轮。

## 验证与限制

最终本机 `npm test` **1499/1499** 通过，0失败/取消/跳过（157.630秒）；`npm ci`、正式构建、`npm run check`（含索引与源码/产物语法）、`git diff --check`通过。原租约用例保持6秒等待，油猴启动用例明确验证即时监控状态及默认不发送，并在断言失败时释放测试页面。

单元/集成回归验证事件顺序、暂停恢复、预算让出、关闭期间成功/失败、草稿编辑、重新挂回控件、图表格式函数变化及索引新鲜度。实际本地浏览器载入模拟预测数据，切换主播/AI设置页，编辑模型草稿并往返，值仍保留；控制台未见error。没有保存测试配置、连接真实直播间或调用模型。

8ms是事件之间检查的合作预算，单个同步处理器仍可能超过预算；未确认业务事实必须保留。界面仍有旧控制器DOM投影，活动页的显式刷新仍需读取源控件；完全消除这部分成本需要逐页迁移领域视图模型。变量动态加载、消息路由及外部包内部不能由静态索引完整证明。

没有采集浏览器性能trace、进程RSS或持续全天实播证据，因此不宣称性能已经达到极限或保证任意环境下的长期稳定。crapper、dryer、mutator不可用，三项未执行。原生宿主没有改动，本机不重复原生测试；远端CI结果另在行动日志记录。
