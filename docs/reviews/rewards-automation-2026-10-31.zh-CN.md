# 福袋检测与自动参与交付

日期：2026-10-31。基于此前手动参与和开奖抓包，将结构化轮次与本人参与回执接入现有福袋红包工具。自动参与和口令参与默认关闭；此次没有操作真实直播报名、领取红包或重放业务接口。

## 用户可见行为

- 即使自动参与关闭，也展示当前已收到的福袋轮次、奖品总量、份数、参与人数、倒计时及开奖状态，未知值保持待确认。
- 开启并保存“自动参与”后，打开本直播间活动详情并点击可用的原生参与／领取按钮。同一轮先持久保存预留，再派发点击；未知提交不会自动重试。
- “参与口令福袋”单独授权原生按钮提交当前活动口令，口令可能出现在公屏。关注、粉丝团、付费、送礼、登录及验证等未完成条件仍等待手动处理。
- 以实际房间、活动编号和当前账号识别福袋成功候选回执；旧版本、其他轮次或其他账号回执不能覆盖较新的本人结果。点击、页面确认、服务器确认分别计数。
- 明确的页面活动编号优先，无编号时只能绑定唯一匹配的开奖时间；近期协议与页面不一致或匹配多轮时等待更新，避免停滞倒计时形成新的提交身份。
- 红包使用独立的预览编号和开始／结束时间，领取结果仍以原生页面为准。开奖名单人数不解释为通用中奖或未中奖结果。
- 立即停止、人工暂停、页面离开、切房、断线与下播会停止相关操作。工具重建、刷新和跨标签页接管继续使用按账号隔离的去重记录。

入口及开关详见 [使用指南](../guides/usage.zh-CN.md#福袋红包自动参与)。真实采集证据见 [手动参与报告](../research/lottery-manual-capture-2026-10-31.zh-CN.md)。

## 领域术语

| 名称 | 含义 |
| --- | --- |
| 页面房间号 | 直播页 URL 中的房间标识，用于配置与存储分区 |
| 实际房间 ID | 平台协议的 room_id，与页面房间号分别处理 |
| 轮次 | 实际房间 ID 与 lottery_id 组成的唯一福袋身份 |
| 本人候选回执 | 同房间、同轮次、当前 UID 的 participate_success 布尔值 |
| 回执版本 | 按整数顺序比较的版本令牌，不解释为时间戳 |
| 页面确认／服务器确认 | 原生页面状态／本人结构化回执，各自保留证据来源 |
| 预留 | 点击前保存的提交记录，结果未知时仍阻止重复提交 |
