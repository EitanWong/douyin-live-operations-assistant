# 运行时重构与性能验证

日期：2026-10-16。范围为事件交接、引擎调度、快照持久化和日志确认；保留自动发送、礼物优先、连击合并、游戏会话与发送前检查点。没有增加全局发送限速或人工审核。

## 本轮实现

- 内容脚本事件队列改用游标，消费后立即清空对象引用，处理过程中分段回收已消费前缀；日志回放与在途任务交错时保持顺序。
- 调度通过一次扫描选择任务；礼物批量感谢只维护最早的五个额外候选，避免全量排序。普通队列淘汰同样改为一次扫描。队列过期和出队原地压缩，礼物索引增量维护。
- 空闲 tick 不再无条件触发界面刷新与快照请求；提前返回的聊天、关键词和游戏路径仍会通知状态变化。
- 新增 src/runtime/journal.js：RuntimeWriter 只保留一个正在写入的快照和一个待写入的最新快照；共享待写入状态的检查点在实际写入完成后才成功。失败拒绝检查点，后续写入可以继续。
- JournalCommitter 单任务运行，每批最多确认 50 条日志；快照成功后才删除日志，失败保留并退避。高峰期间不会创建无限串联的确认批次。页面离开后停止新确认，缓存返回后恢复。
- 引擎快照及恢复对象深度隔离，保留内存中 Infinity 截止时间语义；避免原地出队、重试和连击更新污染旧快照。礼物格式检查失败重新入队时恢复索引。
- 待入账礼物随运行快照保存，重建后继续写入。运行快照不再受普通配置的 1 MiB 人为限制；仍由 Chrome 实际存储配额约束，失败保留日志。

## 可重复测量

运行 npm run benchmark:runtime。脚本位于 scripts/benchmark-runtime.mjs，使用 Node、模拟时钟和 preview 模式，不进行网络发送。

本机环境：macOS arm64，Node v26.11.1。以下为全量测试结束后单独执行的结果；五轮调度测量交替执行参考算法与扫描算法，每项先预热 100 次，再采样 1,000 次。参考算法为同一任务选择语义的 filter/sort 实现，并非整个旧版本。

| 场景 | 本地结果 | 解释 |
| --- | --- | --- |
| 5,000 条任务，参考 filter/sort | 中位数 0.316–0.320 ms，p95 0.401–0.413 ms | 仅用于同语义调度算法比较 |
| 同一队列，单次扫描 | 中位数 0.0143–0.0146 ms，p95 0.0176–0.0217 ms | 不代表整个扩展或发送速度提升相同比例 |
| 1,000 次纯空闲 tick | 0 次 changed 回调 | 没有状态变化时不主动要求 UI/快照刷新 |
| 慢存储期间 1,001 次快照请求 | 2 次实际写入 | 第一次正在写入，其余合并成最新待写入快照 |
| 1,200 条独立礼物 | 1,200 条全部 credited，队列最终为 0 | 300 次预览批次；模拟时钟推进，不是真实发送 |
| 礼物接收计算 / 排空计算 | 约 1.86 ms / 30.90 ms | 不包含实际存储、网页控件与网络延迟 |
| 待处理状态堆增量 | GC 后约 1.56 MiB | 单次本地诊断，没有可比旧版内存基线 |
| 待处理 / 清理后快照 JSON | 908,000 / 1,496 字节 | 模拟排空后推进十分钟触发清理，不是内存降幅 |

## 回归与边界

- npm test：169 项通过，0 失败。包含快照隔离、慢存储合并、检查点失败恢复、超过 100 条待确认日志、页面离开、2,400 条突发与回放交错、连续队列回收、待入账礼物刷新恢复，以及原有发送与游戏用例。
- npm run check、独立目录正式构建、正式 bundle 语法检查、git diff --check 均通过。开发监听器继续维护 dist，正式验证使用 DOUYIN_DIST_DIR=/tmp/douyin-perf-build。
- Playwright 能读取本地模拟器页面；本轮没有取得有效浏览器性能 trace，因此不报告浏览器 CPU、帧率、INP、LCP 或真实扩展内存改善。
- 没有向真实抖音直播间发送消息；平台控件延迟、持续数小时运行、后台休眠与浏览器崩溃仍需实播验证。
- 不能用丢弃未发送礼物来限制积压内存；长期无法发送时，尚未完成的业务数据仍会增长。Chrome 配额不足仍可能阻止持久化。页面卸载不能保证异步写入完成，已成功写入的日志用于恢复。
- 网页点击与落盘之间仍存在极小的重复发送窗口；断线期间平台未重放的数据、日志落盘前进程崩溃，以及数据被清除，都不在本地恢复保证范围内。
- 待入账快照恢复已验证，但没有改变账本对过旧事件的过滤和历史去重缓存范围，不据此声称任意长时间离线仍可完整补账。
