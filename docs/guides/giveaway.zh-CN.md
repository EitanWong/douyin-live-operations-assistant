# 互动抽奖

在「扩展工具 → 互动抽奖」创建由本机运营的抽奖。它使用已采集的观众弹幕与礼物，不创建抖音平台福袋。

1. 添加一项或多项奖品，分别填写名称和中奖人数，再设置倒计时秒数。最多 20 项奖品，合计最多 1000 个名额；每位观众同轮最多中一项奖品。
2. 开放一种或同时开放两种参与方式。指定弹幕去除首尾空格后精确匹配，例如「参与抽奖」。礼物可直接点击「读取 / 刷新礼物目录」，无需先打开网页礼物面板，按名称或 ID 搜索并勾选多种礼物；选中项可直接移除。目录选择按礼物 ID 匹配，也可在输入框用逗号分隔手动补充名称或 ID，例如「玫瑰，小心心」或「463」。指定礼物合并累计，达到数量门槛就直接入池。目录仅读取礼物，不依赖钱包余额或送礼待核对记录；读取失败仍可手动配置。
3. 点击「开始抽奖」。两种方式同时开启时，满足任意一种即可参加；同一观众每轮只有一个名额，重复发送弹幕、送更多礼物或同时使用两种方式不会增加中奖概率。礼物连击的累计帧和重复事件不会重复计数。
4. 可展开「指定观众抽取权重」，按用户 ID 为最多 100 位观众设置 0.01～1000 的权重，最多两位小数；其他观众默认为 1。可从最近观众或历史参与者中选择 ID，也可手动填写 UID 或 `sec:` 标识，不能用昵称。权重是相对机会：仅两人权重为 1、3 时，第一个名额概率为 25%、75%；抽中一人后，从剩余观众按权重继续抽取，因此不是固定中奖百分比。重复弹幕或送更多礼物不会改变已设权重。
5. 可开启「主播参与必中」。必须先识别当前主播 UID；只有主播自己满足本轮参与条件并入池后才生效，占用第一项奖品的一个名额，优先于权重规则。主播不会自动报名，也不会获得额外名额。主播 UID 与规则在开轮时固定。
6. 倒计时结束后，工具按奖品列表顺序，从参与者中按权重无放回抽取并公布各奖品中奖者。参与人数不足时按列表顺序分配；无人参加时保留空结果。抽奖反馈自动发送到公屏；也可点击「复制开奖公告」手动粘贴完整公告。完整公告会注明权重抽取和主播必中规则（如开启）。
7. 在抽奖记录中展开每一轮，查看奖品及名额、固定规则、观众昵称、用户 ID、参与方式、权重与实际所获奖品。CSV 包含本轮权重设置、主播 UID、每位观众抽取权重和所获奖品，便于统计；JSON 保留完整规则、礼物计数、中奖奖品对应关系和弹幕反馈记录。旧版单奖品记录会在读取时自动升级，已保存中奖结果保持不变。记录保存在本机，界面只显示最近 20 轮和每轮最近 100 位参与者，导出包含全部记录。

新轮次始终启用弹幕反馈；旧轮次保留原有反馈状态，避免补发历史公告。可选择是否在开轮和开奖结果弹幕中播报奖品名称；关闭后仍公布中奖者，工具内记录和手动复制的完整公告仍保留奖品。报名保存成功后，工具即时显示已报名人数和最近观众；发送队列会合并确认「报名成功：观众甲、观众乙」，重复弹幕和礼物不重复确认。开轮公告包含参与方式。剩余 5 分钟、1 分钟、30 秒、10 秒时尝试提醒，只有比该节点更长的轮次才适用；出队时按实际剩余秒数播报。后台卡顿、断线或排队导致过期时会跳过提醒，不追发旧时间。

抽奖弹幕复用现有发送队列，抽奖消息至少间隔 2 秒；报名积压超过截止时间不再发成功确认，报名结果仍保存在工具。多奖品、多人中奖会分条发送，长昵称和奖品名称在公屏缩短，完整内容以工具及导出为准。场控未开启时也可发送抽奖消息；配置中的「仅预览」模式只写运行日志，模拟器只显示本地消息。界面「已交给发送队列」表示已可靠入队，平台是否接收需查看运行日志中的发送及公屏回显。存储或发送暂时失败会显示原因并保留待处理公告，不撤销已保存报名或重抽结果。

抽奖弹幕优先使用管理员弹幕；确认管理员通道不可用时回退普通弹幕。发送结果未知时不会换通道重发。

刷新或跨页接管会恢复未提交的公告；每条消息在点击前按房间租约持久认领，避免两页重复发送。已经认领但点击结果未知的消息不会自动重发，可通过工具内完整公告人工核对。开奖结果公告最多保留 24 小时，且不跨直播场次发送。

本轮开始后规则不可修改，取消本轮会保留参与记录。下一轮可重新设置奖品与要求。抽奖独立于场控回复运行；人工暂停场控、下播或切换直播场次会取消本轮。工具停用／页面关闭会停止采集，重新启用／刷新时恢复已保存轮次；关闭期间的互动无法补采。请保持运行页打开并确认连接正常。

同一直播间仅一个标签页可以写入抽奖；其他页面可以查看与导出。刷新时先恢复截止前已进入本地事件日志的参与，再对到期轮次开奖。记录保存失败会停用工具并保留待处理日志，需要恢复存储后重新启用工具。抽取使用浏览器加密随机数，中奖结果保存成功后才展示；已保存结果不会重新抽取。

仅有昵称、没有稳定用户 ID 的弹幕不入池，以免重名观众互相覆盖。礼物要求使用结构化礼物事件，DOM 文本不作为送礼凭据。导出包含观众信息，请妥善保管。

术语：**轮次**是一次规则固定的抽奖；**参与者／入池**表示观众已满足本轮至少一种要求；**中奖者**是倒计时后从参与者中无放回抽出的观众；**奖品名额**是该奖品计划分配给多少人；**权重**是尚未中奖观众在下一次抽取中的相对机会，默认为 1；**主播参与必中**为已入池的本轮主播保留首项奖品一个名额；**礼物门槛**是本轮指定礼物的累计数量；**福袋红包**是平台原生活动，由另一个工具处理。
