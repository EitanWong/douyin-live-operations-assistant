# 使用与配置

## 开始使用

Chrome 安装步骤见[项目首页](../../README.md)。打开已登录的抖音直播间，刷新后点击“场控”。在“设置 → 功能开关”启用需要的模块，再配置对应话术和条件。

默认发送模式为自动发送。首次配置时可在“设置 → 运行规则”选择预览，核对效果后再开始自动发送。每个直播间独立保存配置，设置入口始终可访问。

Tampermonkey 用户可从 [Releases](https://github.com/EitanWong/douyin-live-operations-assistant/releases/latest) 下载 `douyin-live-operations-assistant.user.js`，在脚本管理器中新建脚本、粘贴保存，再刷新直播页。

## 互动规则

| 模块 | 默认或配置方式 |
| --- | --- |
| 礼物感谢 | 默认按连击总价大于 1 钻（至少 2 钻）感谢，可切换为单价门槛 |
| 连击合并 | 默认不等待，按累计数量的新增部分及时感谢；尚未发出的同一用户礼物可合并 |
| 礼物冷却 | 默认无用户间隔，账本独立记录 |
| 进场欢迎 | 默认荣誉等级 ≥30、本房粉丝团等级 ≥1 且已点亮；可配置指定名单 |
| 点赞感谢 | 默认关闭，启用后及时感谢并轮换话术 |
| 关键词 | 按顺序匹配首条规则，可选择包含或精确匹配 |
| 定时消息 | 默认关闭，支持多组间隔、北京时间时段、跨午夜和互动避让 |

房间号与主播 UID 分开配置。身份自动识别失败时，在连接诊断中核对主播和当前账号，必要时手动填写。本人点赞、礼物和聊天会按账号身份过滤；昵称相同的其他观众仍按不同 UID 处理。

欢迎名单支持 UID、sec UID 和精确昵称，也可从最近观众中选择。指定名单模式可绕过等级条件；资料不足时不判定条件达标。

每行一条话术，按顺序轮换。支持的变量：

| 场景 | 变量 |
| --- | --- |
| 欢迎 | `{user}`、`{level}`、`{fanLevel}` |
| 礼物 | `{user}`、`{gift}`、`{count}`、`{value}`、`{unit}` |
| 点赞 | `{user}`、`{count}` |
| 关键词 | `{user}` |

可在连接诊断中导入[示例配置](../../examples/sample-room.json)，检查后保存。示例使用预览模式。

## AI

1. 在设置中填写完整接口地址、模型、API Key、场控风格和本场资料。
2. Chrome 扩展需在工具栏弹窗中授权该服务域名，然后测试连接。
3. 启用 AI 服务及所需模块，再为互动选择 AI 生成或预设话术。

| 服务 | 接口示例 |
| --- | --- |
| DeepSeek | `https://api.deepseek.com/chat/completions` |
| 通义千问 | `https://dashscope.aliyuncs.com/compatible-mode/v1/chat/completions` |
| 火山方舟 | `https://ark.cn-beijing.volces.com/api/v3/chat/completions` |
| Ollama | `http://localhost:11434/v1/chat/completions` |

模型名称按服务账号可用项填写。默认 AI 无调用时间间隔和用户冷却，每小时最多 30 次，上下文最多取最近 180 秒内的 30 条聊天。预览模式也会调用已启用的 AI 服务。旧配置升级时自动清零各互动模块的用户间隔与礼物等待值；定时消息周期和发送失败后的重试退避继续保留。

AI 服务会收到近期公屏昵称、弹幕和配置的资料，费用由服务商收取。密钥默认只在本页使用，勾选记住后保存到扩展或脚本私有存储，按服务域名区分；导出配置不包含密钥。

## @机器人

在功能开关中启用机器人，并核对登录账号身份。观众发送 `@账号昵称 菜单` 查看可用玩法，按提示选择骰子、硬币、猜拳、帮选、猜数字、成语接龙或真心话大冒险。菜单随玩法开关变化。

观众也可直接发送 `开始成语接龙`（或 `开始接龙`）、`开始猜数字`、`开始真心话`、`开始大冒险` 开局，无需 @。房间游戏开始后，观众按提示直接报名或回答，无需每次 @，礼物感谢继续处理。

成语接龙允许主播、登录账号和任意观众随时加入、连续作答；支持同字、同音和常见近音。词库外的四字词只要首字与当前尾字匹配或近音也可接续。重复或接错只提示，不结束；长时间无人参与也保留进度。发送 `@账号昵称 游戏状态` 查看当前词，发送 `@账号昵称 结束游戏` 明确结束，再发 `开始接龙` 可重新开局。其他房间游戏仍有回合、超时和失败结束机制。

发送 `@账号昵称 真心话` 或 `@账号昵称 大冒险` 会直接出题，并等待 60 秒内的回答。被点名的人直接说答案即可，也支持再次 @ 回答；其他观众或主播可自然接话，例如梦想题回答“想当医生”“梦想成为一个大明星”，或发送“回答：……”参与。机器人会称呼实际回答者，并结合题目和答案给予简短反馈。启用 AI 服务后，互动优先调用 AI（不要求开启普通 AI 问答）；未启用、调用失败、繁忙、触发调用额度或 5 秒内未返回时，自动使用内置算法反馈。游戏题目和骰子、猜拳等结果由本地确定，AI 负责接话，不改动结果；菜单和操作提示保持本地响应。`OK了`、`有延迟` 等确认或调试消息不会结束答题；不想回答时可说“跳过”“不想说”“保密”。快捷题回答后结束，房间模式回答后回到报名阶段。其他人也可用简短答案、歌名、地名或表情接话，无需固定前缀。

题库包含 114 道真心话和 87 道可用文字或表情参与的大冒险，按题型抽完一轮前不重复；题目过长时只从当前字数限制下可完整展示的题目中选取。[题库来源与 MIT 许可](../research/interaction-question-sources.zh-CN.md)随项目保留。

## 多主播与收入统计

在“设置 → 主播管理”添加直播间地址，通过“打开并配置”保存各主播的功能开关、话术、AI 配置和估算比例。相同 AI 服务域名的密钥可共用。

启用收入统计后，场控暂停或礼物感谢关闭时仍会记录收到的其他观众礼物。默认按 0.05 元/钻估算收入，可在礼物配置中调整。统计按北京时间归日、按月汇总；修改比例只影响后续礼物。未知单价另行计数，可按礼物 ID 或名称补充价格。

“直播互动 → 收入统计”可切换主播与月份、查看日明细并导出 JSON。已入账礼物和榜单估值保存在浏览器本地，刷新网页、重新打开直播间或扩展后台重启后会自动读取历史数据；重复礼物按已保存的连击进度去重。历史账本不会因新增采样自动按90天清理。卸载扩展或清除数据会删除账本；需要备份时导出月报。

## 运行与恢复

发送控件按队列串行处理，运行规则不设置全局发送频率上限。礼物优先，等待中的机器人任务会获得调度机会。普通互动有时效和队列容量；礼物感谢和结算状态各受 2,000 条/组的资源边界约束。触及时保留已持久化事件，停止继续交接，释放积压后手动恢复。点击前确认未发送的暂时故障可退避重试。

手动暂停、修改配置和切换房间会停止当前互动。页面刷新通过状态快照及未确认日志恢复，按主播的自动开始配置决定是否续跑。点击前会先保存发送意图。刷新前正在发送或等待回显的消息恢复为“结果未知”，不会自动重发；普通待发送任务继续保留。没有平台幂等接口，手动重试仍可能重复。

消息默认直接自动发送，不需要逐条核对。“已点击”表示已操作发送控件，输入框清空不代表平台接受。只有结构化公屏事件的本人 UID / sec UID、文本和时间相符，才标为“已回显”，并记录消息 ID 和延迟；不会通过昵称或 DOM 弹幕猜测。8 秒未收到回显转为“结果未知”；已识别的平台错误提示标为“明确失败”。连接诊断中可选择“确认重试（可能重复）”或“已处理，不再重发”。发送失败、手动草稿、控件重绘和结果未知都会保留任务并继续运行，只有用户明确点击“立即暂停”才暂停场控。

连接诊断的“采集与存储”显示事件积压、隔离数、缺口和存储用量。扩展交接及页面桥接各限制为 4,096 条、约 8 MiB；解码队列限制为 256 帧、16 MiB。单事件最多尝试三次，持续失败事件进入隔离区；配额、存储水位或业务背压故障只暂停对应的数据交接并提示处理，不暂停场控发送。存储达到实际配额的 80% 后拒绝新增日志，预留空间用于快照、确认和恢复。

先处理发送记录与存储故障，再点击“恢复采集与重试隔离事件”。恢复时优先交接已持久化日志，缓冲预留一个恢复槽位，避免未落盘的新事件阻挡日志确认和空间释放。“导出恢复数据”包含当前未完成任务、待入账事实、内存缓冲、隔离事件和本房间持久日志；导出不会删除数据。达到缓冲上限后新增事件或帧可能未采集，缺口会明确显示，不能承诺自动补回。尚未落盘的内存缓冲在关闭页面后无法保证恢复。

## 排查

- 未收到事件：在连接诊断检查连接、帧数和解析错误，再刷新直播页。DOM 备用通道只补新弹幕。
- 发送控件识别失败：在连接诊断定位输入框和发送按钮后保存。
- 提示其他页面占用：同一浏览器配置文件、同一房间只能一页运行；暂停或关闭持锁页后接管。
- AI 失败：核对接口、模型权限、Key、余额及服务域名授权。
- 礼物统计差异：核对门槛、未知单价、本人过滤、连击累计及实际采集时段。
